| Operador / Truco               | Qué hace                     | Ejemplo                                |
| ------------------------------ | ---------------------------- | -------------------------------------- |
| `"texto"`                      | Busca frase exacta           | `"machine learning"`                   |
| `-palabra`                     | Excluye resultados           | `jaguar -carro`                        |
| `site:web.com`                 | Busca dentro de una web      | `site:reddit.com teclados`             |
| `site:.edu`                    | Busca en dominios educativos | `site:.edu ai filetype:pdf`            |
| `filetype:pdf`                 | Busca archivos específicos   | `economia filetype:pdf`                |
| `intitle:`                     | Palabra en el título         | `intitle:"curso python"`               |
| `allintitle:`                  | Varias palabras en el título | `allintitle:python flask auth`         |
| `inurl:`                       | Palabra en URL               | `inurl:login admin`                    |
| `allinurl:`                    | Varias palabras en URL       | `allinurl:react dashboard`             |
| `OR`                           | Una opción u otra            | `lenovo OR asus`                       |
| `*`                            | Comodín dentro de frases     | `"mejor * calidad precio"`             |
| `..`                           | Rango de números/fechas      | `laptop 500..1000`                     |
| `related:`                     | Sitios similares             | `related:netflix.com`                  |
| `cache:`                       | Ver versión cacheada         | `cache:openai.com`                     |
| `define:`                      | Definiciones rápidas         | `define:serendipia`                    |
| `before:`                      | Resultados antes de fecha    | `bitcoin before:2022-01-01`            |
| `after:`                       | Resultados después de fecha  | `ai after:2024-01-01`                  |
| `AROUND(X)`                    | Palabras cercanas            | `apple AROUND(3) privacy`              |
| `source:`                      | Filtrar noticias/fuentes     | `ai source:bbc`                        |
| `mapa`                         | Buscar lugares rápido        | `cafes bogota`                         |
| `weather:`                     | Clima rápido                 | `weather bogota`                       |
| `stocks:`                      | Información bursátil         | `stocks:NVDA`                          |
| `site:reddit.com`              | Opiniones reales/comunidad   | `site:reddit.com mejor monitor`        |
| `site:stackoverflow.com`       | Soluciones de programación   | `site:stackoverflow.com react error`   |
| `site:github.com`              | Código/proyectos             | `site:github.com nextjs auth`          |
| `site:arxiv.org`               | Papers científicos           | `site:arxiv.org transformers`          |
| `ext:pdf`                      | Igual que filetype           | `manual blender ext:pdf`               |
| Comillas + error               | Buscar errores exactos       | `"ModuleNotFoundError"`                |
| Buscar por fecha               | Resultados recientes         | Herramientas → Última semana           |
| Google Images                  | Buscar por imagen            | subir foto en imágenes                 |
| `translate`                    | Traducción rápida            | `translate hola to english`            |
| Calculadora Google             | Operaciones rápidas          | `(25*18)/3`                            |
| Conversión rápida              | Monedas/unidades             | `100 usd a cop`                        |
| Temporizador                   | Timer rápido                 | `timer 10 minutes`                     |
| Cronómetro                     | Stopwatch integrado          | `stopwatch`                            |
| Vuelos                         | Buscar vuelos                | `flights bogota madrid`                |
| Hoteles                        | Buscar hoteles               | `hotels medellin`                      |
| Combinar operadores            | Búsquedas avanzadas          | `site:github.com react auth -firebase` |
| Buscar leaks/info pública      | PDFs/documentos públicos     | `site:gov.co filetype:pdf presupuesto` |
| Buscar perfiles                | Encontrar personas           | `"Juan Perez" site:linkedin.com`       |
| Buscar datasets                | Datos abiertos               | `covid dataset csv`                    |
| Buscar IA prompts              | Prompts compartidos          | `site:reddit.com chatgpt prompts`      |
| Buscar torrents indirectamente | Índices públicos             | `"ubuntu iso" magnet`                  |
| Buscar contenido eliminado     | Cache/web archive            | `cache:web.com`                        |
