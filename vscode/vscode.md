# 📘 ATAJOS MÁS ÚTILES DE VISUAL STUDIO CODE

---

# 📘 🟢 NAVEGACIÓN

| Atajo                  | Acción                                                    |
| ---------------------- | --------------------------------------------------------- |
| `Ctrl + ← / →`         | 👉 Moverse entre palabras                                 |
| `Ctrl + Shift + ← / →` | 👉 Seleccionar palabras                                   |
| `Ctrl + G`             | 👉 Ir a una línea específica                              |
| `Ctrl + P`             | 👉 Buscar archivos                                        |
| `Ctrl + Shift + O`     | 👉 Ver métodos, propiedades y símbolos del archivo        |
| `@`                    | 👉 Buscar métodos y propiedades dentro del archivo actual |

> [!TIP]
> `Ctrl + P` es uno de los atajos más rápidos para navegar proyectos grandes sin usar el explorador de archivos.

---

# 📘 🔵 MULTICURSOR

| Atajo                | Acción                                                       |
| -------------------- | ------------------------------------------------------------ |
| `Ctrl + Alt + ↑ / ↓` | 👉 Crear múltiples cursores                                  |
| `Shift + Alt + I`    | 👉 Agregar cursor al final de todas las líneas seleccionadas |
| `Ctrl + D`           | 👉 Seleccionar siguiente coincidencia                        |
| `Ctrl + Shift + L`   | 👉 Seleccionar todas las coincidencias                       |

> [!IMPORTANT]
> El multicursor es una de las herramientas más potentes de VS Code para editar múltiples líneas simultáneamente.

---

# 📘 🟣 EDICIÓN

| Atajo                 | Acción                     |
| --------------------- | -------------------------- |
| `Shift + Alt + ↑ / ↓` | 👉 Duplicar línea          |
| `Alt + ↑ / ↓`         | 👉 Mover línea             |
| `Ctrl + Shift + K`    | 👉 Eliminar línea completa |
| `Ctrl + /`            | 👉 Comentar línea          |
| `Shift + Alt + A`     | 👉 Comentar bloque         |

> [!TIP]
> Duplicar y mover líneas permite refactorizar código mucho más rápido que copiar y pegar manualmente.

---

# 📘 🟡 BÚSQUEDA

| Atajo              | Acción                            |
| ------------------ | --------------------------------- |
| `Ctrl + Shift + F` | 👉 Buscar en todo el proyecto     |
| `Ctrl + Shift + H` | 👉 Reemplazar en todo el proyecto |

> [!IMPORTANT]
> Estas búsquedas funcionan sobre todos los archivos del proyecto, no solo sobre el archivo abierto.

---

# 📘 🟠 REFACTORIZACIÓN

| Atajo             | Acción                                   |
| ----------------- | ---------------------------------------- |
| `F2`              | 👉 Renombrar variables, métodos o clases |
| `Ctrl + Space`    | 👉 Mostrar autocompletado                |
| `Shift + Alt + F` | 👉 Formatear código                      |

> [!TIP]
> Utiliza `F2` en lugar de buscar y reemplazar manualmente para evitar errores durante una refactorización.

---

# 📘 🔴 TERMINAL Y PANELES

| Atajo              | Acción                         |
| ------------------ | ------------------------------ |
| `` Ctrl + ` ``     | 👉 Abrir terminal              |
| `Ctrl + Shift + E` | 👉 Explorador de archivos      |
| `Ctrl + Shift + G` | 👉 Panel de Git                |
| `Ctrl + Shift + M` | 👉 Panel de errores y warnings |

> [!NOTE]
> Aprender a alternar entre paneles mediante atajos reduce considerablemente el uso del mouse.

---

# 📘 ⚫ TABS

| Atajo              | Acción                             |
| ------------------ | ---------------------------------- |
| `Ctrl + Tab`       | 👉 Cambiar entre archivos abiertos |
| `Ctrl + W`         | 👉 Cerrar archivo actual           |
| `Ctrl + Shift + T` | 👉 Reabrir archivo cerrado         |

> [!TIP]
> `Ctrl + Shift + T` puede salvarte cuando cierras un archivo por accidente.

---

# 📘 ⚪ DEBUG

| Atajo | Acción                |
| ----- | --------------------- |
| `F5`  | 👉 Iniciar debugging  |
| `F9`  | 👉 Agregar breakpoint |
| `F10` | 👉 Step Over          |
| `F11` | 👉 Step Into          |

> [!IMPORTANT]
> Dominar el debugger suele ahorrar mucho más tiempo que llenar el código de `console.log()`.

---

# 📘 🟤 COMANDOS IMPORTANTES

| Atajo              | Acción                                                   |
| ------------------ | -------------------------------------------------------- |
| `Ctrl + Shift + P` | 👉 Abrir Command Palette (todos los comandos de VS Code) |

> [!NOTE]
> La Command Palette es el centro de control de VS Code. Desde allí puedes ejecutar prácticamente cualquier comando disponible.
