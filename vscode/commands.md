# 📘 Keyboard Shortcuts — Atajos de Teclado 🔥

🧠 Atajos esenciales para Windows, Chrome y VS Code  
👉 Mejoran la velocidad de trabajo y la productividad

---

## 📘 🟢 WINDOWS

🧠 Atajos del sistema operativo

- `Shift + Alt` → Cambiar idioma del teclado  
- `Alt + Tab` → Cambiar entre programas  
- `Ctrl + Tab` → Siguiente pestaña  
- `Ctrl + Shift + Tab` → Pestaña anterior  

---

## 📘 🔵 GOOGLE CHROME

🧠 Atajos del navegador

- `Ctrl + T` → Nueva pestaña  
- `Ctrl + N` → Nueva ventana  
- `Ctrl + W` → Cerrar pestaña actual  
- `Ctrl + Shift + T` → Reabrir última pestaña cerrada  

---

## 📘 🟣 VS CODE (EDITOR)

🧠 Atajos para programar más rápido

---

### 📌 EDICIÓN DE CÓDIGO

- `Alt + ↑ / ↓` → Mover línea arriba o abajo  
- `Ctrl + L` → Seleccionar línea actual  
- `Ctrl + Shift + K` → Eliminar línea  
- `Ctrl + K + C` → Comentar línea  
- `Ctrl + K + U` → Descomentar línea  
- `Ctrl + D` → Seleccionar siguiente coincidencia  
- `Ctrl + Shift + L` → Seleccionar todas las coincidencias  

---

### 📌 NAVEGACIÓN

- `Ctrl + B` → Abrir/cerrar barra lateral  
- `Ctrl + J` → Abrir/cerrar terminal  
- `Ctrl + P` → Buscar archivo  
- `Ctrl + G` → Ir a una línea específica  

---

### 📌 BÚSQUEDA

- `Ctrl + F` → Buscar en archivo actual  
- `Ctrl + Shift + F` → Buscar en todo el proyecto  
- `Ctrl + H` → Buscar y reemplazar  

---

### 📌 SCROLL Y MOVIMIENTO

- `Ctrl + ↑ / ↓` → Scroll rápido por líneas  
- `Ctrl + Shift + ↑ / ↓` → Seleccionar líneas  

---

### 📌 DUPLICAR LÍNEAS

- `Alt + Shift + ↑` → Duplicar línea arriba  
- `Alt + Shift + ↓` → Duplicar línea abajo  

---

### 📌 SELECCIÓN AVANZADA

- `Ctrl + Shift + ← / →` → Seleccionar palabra por palabra  
- `Alt + Shift + ← / →` → Expandir selección  
- `Ctrl + Alt + Shift + ← / →` → Selección múltiple avanzada  

---

## 📘 ⚠️ CONSEJOS IMPORTANTES

🧠 No intentes aprender todos los atajos de golpe  

👉 Empieza con los básicos:
- Copiar línea
- Mover línea
- Buscar (`Ctrl + F`)
- Terminal (`Ctrl + J`)

🧠 Los atajos aumentan MUCHO la velocidad de programación
