# 📦 Subir un proyecto a GitHub desde cero (SSH)

    git init
    git add .
    git commit -m "primer commit"

    --------------------------------

    1️⃣ Verificar rama local
      
    git branch

    Si querés usar main:
    git branch -M main

    --------------------------------

    2️⃣ Agregar repositorio remoto (SSH)

    git remote add origin git@github.com:TU_USUARIO/TU_REPO.git

    Ejemplo:
    git remote add origin git@github.com:alobuuls/arkanoid-game.git

    --------------------------------

    3️⃣ Verificar remote

    git remote -v

    --------------------------------

    4️⃣ Subir el proyecto

    git push -u origin main
    # si usás master:
    # git push -u origin master

    --------------------------------

    ✅ A partir de ahora, para subir cambios:

    git add .
    git commit -m "mensaje descriptivo"
    git push

//📘 GIT BÁSICO

    🧠 Git es un sistema de control de versiones.
    Permite llevar registro de cambios, trabajar en ramas,
    y sincronizar proyectos con repositorios remotos (GitHub).
    --------------------------------

    📗 INICIALIZAR REPO

    git init
    🧠 Crea un repositorio local en tu proyecto.
    --------------------------------

    📗 ESTADO DE ARCHIVOS

    git status
    🧠 Muestra archivos modificados, agregados o no rastreados.
    --------------------------------

    📗 AGREGAR ARCHIVOS (STAGING)

    git add <archivo>   # archivo específico
    git add .           # todos los cambios
    🧠 Prepara los archivos para ser commitados.
    --------------------------------

    📗 GUARDAR VERSION (COMMIT)

    git commit -m "mensaje descriptivo"
    🧠 Guarda los cambios en la historia del proyecto.
    --------------------------------

    📗 RAMAS (BRANCHES)

    git branch <nombre-rama>     # crear rama
    git checkout <nombre-rama>   # moverse a la rama (clásico)
    git switch <nombre-rama>     # alternativo moderno
    🧠 Permite trabajar en diferentes líneas de desarrollo sin afectar la principal.
    --------------------------------

    📗 FUSIONAR RAMAS (MERGE)

    git checkout main           # moverse a la rama principal
    git merge <rama>            # fusionar otra rama
    🧠 Integra los cambios de otra rama en la actual.
    --------------------------------

    📗 REPOSITORIO REMOTO (GITHUB)

    git remote add origin git@github.com:USUARIO/REPO.git
    git remote -v
    🧠 Conecta tu repo local con GitHub y verifica la conexión.
    --------------------------------

    📗 SUBIR CAMBIOS (PUSH)

    git push -u origin main         # subir por primera vez
    git push                        # después de configurar upstream
    git push -u origin <rama>       # subir rama nueva
    🧠 `-u` hace que Git recuerde la rama como predeterminada para futuros push.
    --------------------------------

    📗 TRAER CAMBIOS (PULL)

    git pull origin main
    git pull origin <rama>
    🧠 Actualiza tu repositorio local con los cambios del remoto.
    --------------------------------

    📗 EXTRAS ÚTILES

    git log                    # historial de commits
    git branch -d <rama>       # borrar rama local
    git checkout -- <archivo>  # deshacer cambios no staged
    git reset --soft HEAD~1    # deshacer commit, mantener cambios
    git reset --hard HEAD~1    # deshacer commit y cambios
    git stash                  # guardar cambios sin commit
    git stash pop              # recuperar cambios guardados

    --------------------------------

    📗 FLUJO TÍPICO DE TRABAJO

    1️⃣ git status       → ver cambios
    2️⃣ git add .        → preparar cambios
    3️⃣ git commit -m "" → guardar
    4️⃣ git push         → subir a GitHub
