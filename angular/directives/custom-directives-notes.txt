//📘 DIRECTIVAS PERSONALIZADAS EN ANGULAR (CUSTOM DIRECTIVES)

    🧠 Son directivas creadas por el desarrollador

    👉 Permiten reutilizar lógica y comportamiento en el HTML

    📘 🟢 ¿QUÉ SON?

        🧠 Son clases con el decorador @Directive

        👉 Sirven para:
           • modificar comportamiento  
           • aplicar estilos  
           • reaccionar a eventos  

        💡 Ejemplo

            @Directive({
              selector: '[appHighlight]'
            })

    📘 🔵 TIPOS DE DIRECTIVAS PERSONALIZADAS

        🧠 1. De atributo (las más comunes)

        👉 Modifican apariencia o comportamiento

        ✔ No cambian el DOM  
        ✔ Se usan como atributo  

        🧠 2. Estructurales (más avanzadas)

        👉 Cambian el DOM

        ✔ Usan *  
        ✔ Ej: *miIf  

    📘 🟣 CREAR UNA DIRECTIVA

        🧠 Con Angular CLI

            ng g directive highlight

        👉 Genera automáticamente la directiva

    📘 🟡 EJEMPLO BÁSICO

        💡 TypeScript

            import { Directive, ElementRef } from '@angular/core';

            @Directive({
              selector: '[appHighlight]'
            })
            export class HighlightDirective {

              constructor(private el: ElementRef) {
                this.el.nativeElement.style.backgroundColor = 'yellow';
              }

            }

        💡 HTML

            <p appHighlight>Texto resaltado</p>

    📘 🟠 ESCUCHAR EVENTOS

        🧠 Usando HostListener

        💡 Ejemplo

            import { HostListener } from '@angular/core';

            @HostListener('mouseenter')
            onMouseEnter() {
              this.el.nativeElement.style.color = 'red';
            }

    📘 🔴 MODIFICAR EL DOM (BUENA PRÁCTICA)

        🧠 Usar Renderer2

        💡 Ejemplo

            constructor(private el: ElementRef, private renderer: Renderer2) {}

            ngOnInit() {
              this.renderer.setStyle(this.el.nativeElement, 'color', 'blue');
            }

        👉 Evita manipular el DOM directamente

    📘 ⚫ RECIBIR VALORES (@Input)

        🧠 Permite configurar la directiva

        💡 Ejemplo

            @Input() appHighlight: string = '';

            ngOnInit() {
              this.renderer.setStyle(this.el.nativeElement, 'color', this.appHighlight);
            }

        💡 HTML

            <p [appHighlight]="'green'">Texto</p>

    📘 ⚪ REGISTRO

        🧠 Debe declararse en un módulo

        💡 Ejemplo

            declarations: [HighlightDirective]

    📘 🟤 ¿CUÁNDO USARLAS?

        ✔ Reutilizar comportamiento  
        ✔ Aplicar lógica en múltiples elementos  
        ✔ Evitar repetir código  
        ✔ Crear funcionalidades personalizadas  

    📘 🟢 BUENAS PRÁCTICAS

        ✔ Usar Renderer2  
        ✔ Hacerlas reutilizables  
        ✔ Mantenerlas simples  
        ✔ Usar nombres claros (appHighlight)  

    📘 🟡 ERRORES COMUNES

        ❌ Manipular DOM directamente
        ❌ No usar selector correcto
        ❌ Hacer lógica muy compleja
        ❌ No declararlas en módulo

    ⚠️ COSAS IMPORTANTES

        🧠 selector con [] = atributo
        🧠 No crean HTML
        🧠 Modifican comportamiento
        🧠 Son reutilizables

    ✨ RESUMEN

        🧠 Custom Directives = lógica reutilizable en HTML

        👉 Modifican comportamiento o estilos  
        👉 Se crean con @Directive  
        👉 Se usan como atributos  

        👉 Poder real para extender Angular 🚀
