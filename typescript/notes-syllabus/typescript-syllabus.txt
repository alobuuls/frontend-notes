🟢 2️⃣ Tipos básicos

Aquí empieza el corazón de TypeScript.

Tipos primitivos:

- string
- number
- boolean
- null
- undefined
- any
- unknown
- void
- never

Ejemplo:

let nombre: string = "Juan";
let edad: number = 25;
let activo: boolean = true;

📌 Aprenderás:
- Cómo declarar variables tipadas
- Cuándo usar any y cuándo evitarlo


🟢 3️⃣ Tipos en arrays y objetos

📦 Arrays:

let numeros: number[] = [1, 2, 3];

o

let numeros: Array<number> = [1, 2, 3];


🧱 Objetos:

let usuario: { nombre: string; edad: number };

📌 Aprenderás:
- Tipar estructuras de datos
- Tipar objetos complejos


🟢 4️⃣ Tipos personalizados

Aquí empieza lo potente.

📌 Type:

type Usuario = {
  nombre: string;
  edad: number;
};

📌 Interface:

interface Usuario {
  nombre: string;
  edad: number;
}

📌 Aprenderás:
- Diferencia entre type y interface
- Reutilizar tipos


🟢 5️⃣ Funciones tipadas

function sumar(a: number, b: number): number {

}

📌 Conceptos:
- Tipos en parámetros
- Tipo de retorno
- Funciones flecha tipadas
- Parámetros opcionales

function saludar(nombre?: string)

🟡 🔟 Generics (MUY IMPORTANTE 🔥)

function identity<T>(value: T): T {
  return value;
}

📌 Permite reutilizar código tipado

Ejemplo:

function getFirst<T>(arr: T[]): T {
  return arr[0];
}
