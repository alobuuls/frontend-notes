# 🟢 ATAJOS DE TECLADO (WINDOWS)

## 🖥️ SISTEMA

| Atajo | Acción |
|--------|--------|
| `Alt` + `Tab` | Cambiar entre programas abiertos |
| `Ctrl` + `Alt` + `Tab` | Cambiar entre programas (queda abierto selector) |
| `Ctrl` + `Esc` | Abrir menú Inicio |
| `Ctrl` + `Shift` + `Esc` | Abrir Administrador de tareas |
| `Ctrl` + `Alt` + `Supr` | Pantalla de seguridad |
| `Win` + `L` | Bloquear equipo |
| `Win` + `D` | Mostrar escritorio |
| `Win` + `M` | Minimizar todas las ventanas |
| `Win` + `Shift` + `M` | Restaurar ventanas minimizadas |
| `Win` + `Tab` | Vista de tareas |
| `Win` + `R` | Ejecutar |
| `Win` + `I` | Configuración |
| `Win` + `X` | Menú avanzado de Windows |
| `Win` + `U` | Centro de accesibilidad |
| `Win` + `Enter` | Narrador |

---

## 🪟 VENTANAS

| Atajo | Acción |
|--------|--------|
| `Win` + `↑` | Maximizar ventana |
| `Win` + `↓` | Restaurar / minimizar ventana |
| `Win` + `←` | Anclar ventana a la izquierda |
| `Win` + `→` | Anclar ventana a la derecha |
| `Alt` + `F4` | Cerrar ventana |

---

## 🗂️ ESCRITORIOS VIRTUALES

| Atajo | Acción |
|--------|--------|
| `Ctrl` + `Win` + `D` | Nuevo escritorio |
| `Ctrl` + `Win` + `←` | Escritorio anterior |
| `Ctrl` + `Win` + `→` | Escritorio siguiente |
| `Ctrl` + `Win` + `F4` | Cerrar escritorio actual |

---

## 🖼️ CAPTURAS

| Atajo | Acción |
|--------|--------|
| `Win` + `Shift` + `S` | Herramienta de recortes |
| `Win` + `Impr` Pant | Captura y guarda automáticamente |
| `Alt` + `Impr` Pant | Captura ventana activa |

---

## ⌨️ TECLADO / SISTEMA

| Atajo | Acción |
|--------|--------|
| `Shift` + `Alt` | Cambiar idioma del teclado |
| `Win` + `Ctrl` + `Espacio` | Cambiar idioma |
| `Shift` + `Insert` | Pegar |
| `Ctrl` + `C` | Copiar |
| `Ctrl` + `V` | Pegar |
| `Ctrl` + `X` | Cortar |
| `Ctrl` + `Z` | Deshacer |
| `Ctrl` + `Y` | Rehacer |
| `Ctrl` + `A` | Seleccionar todo |
| `Ctrl` + `Tab` | Siguiente pestaña |
| `Ctrl` + `Shift` + `Tab` | Pestaña anterior |
