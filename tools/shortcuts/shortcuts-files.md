# 📁 EXPLORADOR DE ARCHIVOS — ATAJOS COMPLETOS 🔥

---

# 📂 NAVEGACIÓN

| Atajo | Acción |
|--------|--------|
| `Alt` + `←` | Atrás |
| `Alt` + `→` | Adelante |
| `Alt` + `↑` | Carpeta superior |
| `Alt` + `D` | Seleccionar barra de direcciones |
| `Ctrl` + `L` | Ir a barra de direcciones |
| `Borrar` | Volver a carpeta anterior |
| `Ctrl` + `E` | Seleccionar búsqueda |

---

# 📄 ARCHIVOS Y CARPETAS

| Atajo | Acción |
|--------|--------|
| `F2` | Renombrar archivo |
| `Supr` | Eliminar |
| `Shift` + `Supr` | Eliminar permanentemente |
| `Ctrl` + ``Shift`` + `N` | Nueva carpeta |
| `Ctrl` + `C` | Copiar |
| `Ctrl` + `X` | Cortar |
| `Ctrl` + `V` | Pegar |
| `Ctrl` + `Z` | Deshacer acción |
| `Ctrl` + `Y` | Rehacer acción |
| `Ctrl` + `A` | Seleccionar todo |
| `Ctrl` + `D` | Eliminar selección |

---

# 🖱️ ACCIONES CON MOUSE

| Acción | Resultado |
|--------|----------|
| `Shift` + `Click` derecho | Abrir opciones avanzadas (incluye CMD/PowerShell aquí) |
| `Ctrl` + `Arrastrar` archivo | Copiar archivo |
| `Shift` + `Arrastrar` archivo | Mover archivo (forzado) |
| `Alt` + `Doble` click | Propiedades rápidas (alternativo en algunos sistemas) |

---

# 📊 PROPIEDADES Y DETALLES

| Atajo | Acción |
|--------|--------|
| `Alt` + `Enter` | Abrir propiedades |
| `Ctrl` + `Enter` | Abrir archivo seleccionado |
| `Shift` + `Enter` | Abrir en nueva ventana (algunas apps) |

---

# 👀 VISTA Y VISUALIZACIÓN

| Atajo | Acción |
|--------|--------|
| `Ctrl` + ``Shift`` + `1` | Iconos extra grandes |
| `Ctrl` + ``Shift`` + `2` | Iconos grandes |
| `Ctrl` + ``Shift`` + `3` | Iconos medianos |
| `Ctrl` + ``Shift`` + `4` | Iconos pequeños |
| `Ctrl` + `Mouse Scroll` | Cambiar tamaño de iconos |
| `Alt` + `P` | Panel de vista previa |
| `Alt` + ``Shift`` + `P` | Panel de detalles |

---

# 🔍 BÚSQUEDA

| Atajo | Acción |
|--------|--------|
| `Ctrl` + `F` | Buscar archivos |
| `F3` | Activar búsqueda |
| `Ctrl` + ``Shift`` + `F` | Búsqueda avanzada (en algunos sistemas) |

---

# 🧠 SELECCIÓN AVANZADA

| Atajo | Acción |
|--------|--------|
| `Shift` + `Click` | Selección en rango |
| `Ctrl` + `Click` | Selección múltiple |
| `Ctrl` + ``Shift`` + `Click` | Selección avanzada continua |
| `Shift` + `Flechas` | Selección con teclado |

---

# ⚙️ SISTEMA Y UTILIDADES

| Atajo | Acción |
|--------|--------|
| `Win` + `E` | Abrir Explorador de archivos |
| `Win` + `R` → `.` | Abrir carpeta actual en Ejecutar |
| `Win` + `R` → `..` | Subir carpeta en Ejecutar |
| `Shift` + `Click derecho` | Opciones avanzadas (CMD/Terminal) |

---

# 🧠 ATAJOS OCULTOS ÚTILES

| Atajo | Acción |
|--------|--------|
| `Alt` + `Enter` | Propiedades |

| `Ctrl` + `L` | Enfocar barra de dirección |

---

# 💡 IDEA CLAVE

👉 El Explorador de archivos se domina con:

✔ `Alt` = navegación  
✔ `Ctrl` = acciones rápidas  
✔ `Shift` = acciones avanzadas  
✔ `Click derecho` = herramientas ocultas
