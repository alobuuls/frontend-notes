# 🌐 GOOGLE CHROME — ATAJOS COMPLETOS 🔥 

---

# 📑 PESTAÑAS

| Atajo | Acción |
|--------|--------|
| `Ctrl` + `T` | Nueva pestaña |
| `Ctrl` + `W` | Cerrar pestaña |
| `Ctrl` + `Shift` + `T` | Reabrir pestaña cerrada |
| `Ctrl` + `Tab` | Siguiente pestaña |
| `Ctrl` + `Shift` + `Tab` | Pestaña anterior |
| `Ctrl` + `1`–`9` | Ir a pestaña específica |
| `Ctrl` + `Page Down` | Siguiente pestaña (alternativo) |
| `Ctrl` + `Page Up` | Pestaña anterior (alternativo) |
| `Ctrl` + `F4` | Cerrar pestaña |

---

# 🪟 VENTANAS

| Atajo | Acción |
|--------|--------|
| `Ctrl` + `N` | Nueva ventana |
| `Ctrl` + `Shift` + `N` | Ventana incógnito |
| `Ctrl` + `Shift` + `W` | Cerrar ventana |
| `Ctrl` + `Shift` + `Q` | Cerrar Chrome |
| `Alt` + `F4` | Cerrar Chrome |
| `Ctrl` + `Shift` + `N` (Linux/Win) | Incógnito (alternativo común) |

---

# 🔍 NAVEGACIÓN

| Atajo | Acción |
|--------|--------|
| `Alt` + `←` | Atrás |
| `Alt` + `→` | Adelante |
| `Borrar` | Atrás (en algunas configuraciones antiguas) |
| `F5` | Actualizar |
| `Ctrl` + `R` | Actualizar |
| `Ctrl` + `Shift` + `R` | Actualizar sin caché (hard reload) |
| `Ctrl` + `F5` | Hard refresh alternativo |

# 💡 IDEA CLAVE

👉 Chrome se domina con:

✔ `Ctrl` = navegación  
✔ `Ctrl` + `Shift` = acciones avanzadas  
✔ `Alt` = movimiento rápido  
✔ `F12` = desarrollo  
✔ `F11` = pantalla completa
