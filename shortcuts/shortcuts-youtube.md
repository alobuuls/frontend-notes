# 🎥 YOUTUBE — ATAJOS COMPLETOS 🔥

---

## ▶️ REPRODUCCIÓN

| Atajo | Acción |
|--------|--------|
| `K` | Pausar / Reanudar |
| `Espacio` | Pausar / Reanudar |
| `F` | Pantalla completa |
| `Esc` | Salir de pantalla completa |
| `M` | Silenciar / activar sonido |
| `Shift` + `.` | Aumentar velocidad |
| `Shift` + `,` | Disminuir velocidad |

---

## ⏩ NAVEGACIÓN DEL VIDEO

| Atajo | Acción |
|--------|--------|
| `J` | Retroceder 10 segundos |
| `L` | Avanzar 10 segundos |
| `←` | Retroceder 5 segundos |
| `→` | Avanzar 5 segundos |
| `Inicio` | Ir al inicio del video |
| `Fin` | Ir al final del video |

---

## 🔊 VOLUMEN

| Atajo | Acción |
|--------|--------|
| `↑` | Subir volumen |
| `↓` | Bajar volumen |
| `M` | Silenciar / activar sonido |

---

## 🎞️ CONTROL PRECISO (FRAMES)

| Atajo | Acción |
|--------|--------|
| `,` | Frame anterior (video pausado) |
| `.` | Frame siguiente (video pausado) |

---

## 🔢 SALTOS POR PORCENTAJE

| Atajo | Acción |
|--------|--------|
| `0` | Inicio del video |
| `1` | 10% |
| `2` | 20% |
| `3` | 30% |
| `4` | 40% |
| `5` | 50% |
| `6` | 60% |
| `7` | 70% |
| `8` | 80% |
| `9` | 90% |

---

## 📃 PLAYLIST

| Atajo | Acción |
|--------|--------|
| `Shift` + `N` | Siguiente video |
| `Shift` + `P` | Video anterior |

---

## 💬 SUBTÍTULOS

| Atajo | Acción |
|--------|--------|
| `C` | Activar / desactivar subtítulos |

---

## ⚙️ CONTROLES EXTRA (ÚTILES)

| Atajo | Acción |
|--------|--------|
| `Shift` + `>` | Aumentar velocidad de reproducción |
| `Shift` + `<` | Reducir velocidad de reproducción |
| `I` | Mini reproductor |
| `T` | Modo teatro |
| `/` | Ir a barra de búsqueda de YouTube |

---

## 🧠 RESUMEN RÁPIDO

| Categoría | Qué controlas |
|------------|--------------|
| ▶️ Reproducción | Play, pausa, velocidad |
| ⏩ Navegación | Saltos en el video |
| 🔊 Audio | Volumen y mute |
| 🎞️ Frames | Control preciso |
| 🔢 Saltos rápidos | Ir a porcentaje |
| 📃 Playlist | Cambiar videos |
| 💬 Subtítulos | Activar texto |

---

## 💡 IDEA CLAVE

👉 YouTube se controla con 3 cosas:

- ✔ `K` / `Espacio` → reproducción  
- ✔ `J` / `L` → movimiento  
- ✔ `0`-`9` → saltos rápidos
