# 🧠 9. PARADIGMA LÓGICO

La programación lógica utiliza **hechos, reglas y relaciones** para describir un problema.

En lugar de especificar exactamente cómo ejecutar las instrucciones, describes:

```text
Hechos
 +
Reglas
 +
Relaciones
```

Por ejemplo, conceptualmente:

```text
Hecho:
Juan es padre de Ana.

Regla:
Si X es padre de Y,
entonces X es familiar de Y.
```

El sistema puede utilizar estas reglas para obtener conclusiones.

Uno de los lenguajes más conocidos es:

```text
Prolog
```

### 🧠 Idea principal

> **Lógico = describir hechos y reglas para que el sistema pueda deducir resultados.**

Para desarrollo web moderno no es de los paradigmas que más utilizarás, pero es importante conocerlo para tener una visión completa de los paradigmas clásicos.
