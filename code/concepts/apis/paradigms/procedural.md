# 🧱 3. PARADIGMA PROCEDURAL

El paradigma **procedural** organiza el programa mediante **procedimientos o funciones** que realizan tareas específicas.

Es considerado una forma de programación imperativa.

Conceptualmente:

```text
Programa
   │
   ├── procedimiento A
   ├── procedimiento B
   ├── procedimiento C
   └── procedimiento D
```

Por ejemplo:

```ts
function validateUser() {
  // ...
}

function createUser() {
  // ...
}

function sendEmail() {
  // ...
}
```

El programa puede dividirse en diferentes procedimientos:

```text
main()
 │
 ├── validateUser()
 ├── createUser()
 └── sendEmail()
```

### 🧠 Características

* procedimientos
* funciones
* separación de tareas
* reutilización de lógica
* flujo de ejecución explícito

### 📌 Relación

```text
Imperativo
     ↓
Procedural
```

La programación procedural normalmente se considera **un estilo dentro del paradigma imperativo**, no necesariamente un paradigma completamente separado.

### 📌 Idea principal

> **Procedural = organizar el programa en procedimientos que realizan tareas.**
