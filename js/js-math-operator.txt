//📘 MATH EN JAVASCRIPT

🧠 Math es un objeto встроido en JavaScript
que permite hacer operaciones matemáticas.

--------------------------------

📗 Math.random()

🧠 Genera un número aleatorio entre 0 y 1 (sin incluir 1).

🧪 Ejemplo:
Math.random();
// 0.234567...

--------------------------------

📗 Math.floor()

🧠 Redondea hacia abajo (elimina decimales).

🧪 Ejemplo:
Math.floor(4.9);
// 4

--------------------------------

📗 Math.ceil()

🧠 Redondea hacia arriba.

🧪 Ejemplo:
Math.ceil(4.1);
// 5

--------------------------------

📗 Math.round()

🧠 Redondea al número más cercano.

🧪 Ejemplo:
Math.round(4.5);
// 5

--------------------------------

📗 Math.max()

🧠 Devuelve el número MÁS grande.

🧪 Ejemplo:
Math.max(10, 5, 100, 3);
// 100

--------------------------------

📗 Math.min()

🧠 Devuelve el número MÁS pequeño.

🧪 Ejemplo:
Math.min(10, 5, 100, 3);
// 3

--------------------------------

📗 Math.abs()

🧠 Devuelve el valor absoluto (sin signo negativo).

🧪 Ejemplo:
Math.abs(-10);
// 10

--------------------------------

📗 EJEMPLO COMBINADO 🎲

🧪 Número aleatorio entre 1 y 10:

Math.floor(Math.random() * 10) + 1;

--------------------------------

📗 REGLA RÁPIDA 🧠

👉 random → aleatorio  
👉 floor → baja  
👉 ceil → sube  
👉 round → redondea  
👉 max → mayor  
👉 min → menor  
👉 abs → valor positivo
