//📘 DELEGACIÓN DE EVENTOS (EVENT DELEGATION)

🧠 La delegación de eventos es una técnica donde
ponemos un solo event listener en un padre
para manejar eventos de sus hijos.

--------------------------------

📗 ¿POR QUÉ SE USA?

✔ Mejora rendimiento
✔ Evita múltiples listeners
✔ Funciona con elementos dinámicos
✔ Más fácil de mantener

--------------------------------

📗 closest()

🧠 Busca el elemento más cercano que coincida con un selector,
incluyendo el propio elemento o sus padres.

🧪 Ejemplo:

document.addEventListener("click", (e) => {
  const button = e.target.closest(".btn");

  if (button) {
    console.log("Click en botón o hijo del botón");
  }
});

--------------------------------

📗 matches()

🧠 Verifica si el elemento coincide directamente con un selector.

🧪 Ejemplo:

document.addEventListener("click", (e) => {
  if (e.target.matches(".btn")) {
    console.log("Click directo en botón");
  }
});

--------------------------------

📗 DIFERENCIA CLAVE 🧠

closest()
👉 busca en el elemento y sus padres

matches()
👉 verifica SOLO el elemento actual

--------------------------------

📗 CASOS DE USO

🧪 Situación → Usa

✔ Listener en el mismo elemento → matches()
✔ Delegación de eventos → closest()
✔ Click puede venir de hijos → closest()
✔ Validar elemento actual → matches()

--------------------------------

📗 EJEMPLO REAL 🔥

document.body.addEventListener("click", (e) => {
  const item = e.target.closest(".item");

  if (!item) return;

  console.log("Elemento clickeado:", item);
});

--------------------------------

📗 REGLA RÁPIDA 🧠

👉 matches → “¿soy este elemento?”  
👉 closest → “encuentra el padre más cercano”  
👉 delegación → un solo listener para muchos elementos
