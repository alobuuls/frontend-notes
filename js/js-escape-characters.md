# 📘 ESCAPE CHARACTERS (CARACTERES DE ESCAPE)

## 🧠 Los escape characters se usan dentro de strings para representar caracteres especiales o invisibles.

👉 Se escriben con una barra invertida: `\`

---

# 📗 \n

## 🧠 Salto de línea

### 📙 Ejemplo

```js
console.log('Hola\nMundo');
```

### 🧪 Resultado

```text
Hola
Mundo
```

---

# 📗 \t

## 🧠 Tabulación (espacio grande, como una sangría)

### 📙 Ejemplo

```js
console.log('Nombre:\tAna');
```

---

# 📗 \"

## 🧠 Comilla doble dentro de un string con comillas dobles

### 📙 Ejemplo

```js
console.log('Ella dijo: "hola"');
```

---

# 📗 \'

## 🧠 Comilla simple dentro de un string con comillas simples

### 📙 Ejemplo

```js
console.log("Ella dijo: 'hola'");
```

---

# 📗 \\

## 🧠 Representa una barra invertida real

### 📙 Ejemplo

```js
console.log('Ruta: C:\\Users\\Ana');
```

---

# 📗 \r

## 🧠 Retorno de carro (vuelve al inicio de la línea)

---

# 📗 \b

## 🧠 Retroceso (borra un carácter atrás)

---

# 📗 \f

## 🧠 Salto de página (form feed)

---

# 📘 NOTA

## 🧠 Los más usados son:

```text
\n   \t   \"   \'   \\
```

👉 Si ves una `\` dentro de un string,

👉 piensa: “esto es un escape”.

---

# ✨ RESUMEN RÁPIDO

| Escape Character | Función          |
| ---------------- | ---------------- |
| `\n`             | Salto de línea   |
| `\t`             | Tabulación       |
| `\"`             | Comilla doble    |
| `\'`             | Comilla simple   |
| `\\`             | Barra invertida  |
| `\r`             | Retorno de carro |
| `\b`             | Retroceso        |
| `\f`             | Salto de página  |

---

# 🚀 Los más importantes

✅ `\n` → salto de línea

✅ `\t` → tabulación

✅ `\"` → comillas dobles

✅ `\'` → comillas simples

✅ `\\` → barra invertida

👉 Son los que más encontrarás en código JavaScript real.
