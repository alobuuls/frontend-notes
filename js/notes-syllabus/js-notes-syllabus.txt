//📘 ¿QUÉ ES JAVASCRIPT Y CÓMO FUNCIONA?

🧠 JavaScript es un lenguaje de programación interpretado

👉 Se usa principalmente para hacer páginas web interactivas

📘 🟢 1. ¿QUÉ ES JAVASCRIPT?

    🧠 Lenguaje de programación que corre en el navegador

    👉 Permite:
        - Manipular HTML y CSS
        - Responder a eventos (clicks, teclas, etc.)
        - Hacer peticiones a servidores

    💡 Ejemplo:

        console.log('Hola mundo');

📘 🔵 2. ¿DÓNDE SE EJECUTA?

    🧠 Principalmente en el navegador

    👉 Ejemplos:
        - Chrome
        - Firefox
        - Edge

    💡 También puede ejecutarse fuera del navegador:

        Node.js

    👉 Permite usar JS en el backend

📘 🟣 3. ¿CÓMO FUNCIONA?

    🧠 JavaScript es interpretado

    👉 El navegador tiene un motor de JS (ej: V8 en Chrome)

    💡 Flujo:

        Código JS → Motor JS → Ejecución

📘 🟡 4. MOTOR DE JAVASCRIPT

    🧠 Es el que entiende y ejecuta el código

    👉 Ejemplos:
        - V8 (Chrome)
        - SpiderMonkey (Firefox)

    👉 Convierte tu código en algo que la máquina entiende

📘 🟠 5. JAVASCRIPT ES DINÁMICO

    🧠 No necesitas declarar tipos

    💡 Ejemplo:

        let x = 10;
        x = "hola";

    👉 Puede cambiar de tipo fácilmente

📘 🔴 6. JAVASCRIPT ES DE UN SOLO HILO

    🧠 Ejecuta una cosa a la vez

    👉 Usa:
        - Call Stack
        - Event Loop

    💡 Permite manejar tareas async sin bloquear

📘 ⚫ 7. EVENT LOOP (BÁSICO)

    🧠 Maneja tareas asincrónicas

    💡 Ejemplo:

        console.log('1');

        setTimeout(() => {
          console.log('2');
        }, 0);

        console.log('3');

    👉 Resultado:

        1
        3
        2

📘 ⚪ 8. ASINCRONÍA

    🧠 JS puede ejecutar cosas "en segundo plano"

    👉 Ejemplos:
        - setTimeout
        - fetch (APIs)
        - eventos

📘 🟤 9. JAVASCRIPT Y EL DOM

    🧠 Puede modificar la página web

    💡 Ejemplo:

        document.querySelector('h1').textContent = 'Hola';

    👉 Cambia el contenido en pantalla

📘 🟢 10. JAVASCRIPT ES MULTIPARADIGMA

    🧠 Soporta varios estilos:

    👉 Programación:
        - Procedural
        - Orientada a objetos
        - Funcional

📘 🔵 11. JAVASCRIPT EN EL FRONTEND

    🧠 Se ejecuta en el cliente (usuario)

    👉 Controla:
        - Interacciones
        - UI
        - Animaciones

📘 🟣 12. JAVASCRIPT EN EL BACKEND

    🧠 Con Node.js

    👉 Permite:
        - Crear servidores
        - APIs
        - Manejar bases de datos

📘 🟡 13. VENTAJAS

    👉 Fácil de aprender
    👉 Muy usado
    👉 Corre en todos los navegadores
    👉 Gran comunidad

📘 🟠 14. DESVENTAJAS

    👉 Puede ser confuso al inicio
    👉 Tipado débil
    👉 Problemas con this si no se entiende bien

⚠️ COSAS IMPORTANTES

    🧠 JS corre en el navegador y también en backend
    🧠 Es interpretado (no compilado tradicionalmente)
    🧠 Es de un solo hilo pero maneja async
    🧠 Manipula el DOM (clave en web)

✨ RESUMEN

    🧠 JavaScript:

    👉 Hace las páginas interactivas
    👉 Se ejecuta en el navegador
    👉 Usa un motor para correr el código
    👉 Maneja async con Event Loop

    👉 Es el lenguaje base del desarrollo web 🚀

//📘 VARIABLES EN JAVASCRIPT (let, const, var)

🧠 Las variables permiten almacenar datos

👉 Son la base para trabajar con información en JS

📘 🟢 1. ¿QUÉ ES UNA VARIABLE?

    🧠 Es un espacio en memoria para guardar un valor

    💡 Ejemplo:

        let nombre = 'Juan';

    👉 nombre guarda el valor 'Juan'

📘 🔵 2. DECLARAR VARIABLES

    🧠 En JavaScript se usan:

    👉 let
    👉 const
    👉 var

    💡 Ejemplo:

        let edad = 20;
        const pais = 'Colombia';
        var ciudad = 'Bogotá';

📘 🟣 3. LET

    🧠 Variable que puede cambiar su valor

    💡 Ejemplo:

        let numero = 10;
        numero = 20;

    👉 Se puede reasignar

    ⚠️ Tiene alcance de bloque (scope)

📘 🟡 4. CONST

    🧠 Variable constante (no cambia)

    💡 Ejemplo:

        const pi = 3.14;

    👉 NO se puede reasignar:

        pi = 4; // ❌ error

    ⚠️ IMPORTANTE

    🧠 En objetos/arrays sí se pueden modificar propiedades:

        const persona = { nombre: 'Ana' };
        persona.nombre = 'Juan'; // ✅

📘 🟠 5. VAR (ANTIGUO)

    🧠 Forma antigua de declarar variables

    💡 Ejemplo:

        var x = 10;

    👉 Tiene problemas de scope y hoisting

    ⚠️ NO se recomienda usar en código moderno

📘 🔴 6. DIFERENCIAS CLAVE

    🧠 let vs const vs var

    👉 let:
        - Se puede reasignar
        - Scope de bloque

    👉 const:
        - No se puede reasignar
        - Scope de bloque

    👉 var:
        - Se puede reasignar
        - Scope de función (no bloque)

📘 ⚫ 7. SCOPE (ÁMBITO)

    🧠 Define dónde existe la variable

    💡 Ejemplo:

        if (true) {
          let a = 10;
        }

        console.log(a); // ❌ error

    👉 a solo existe dentro del bloque

📘 ⚪ 8. HOISTING

    🧠 JS "sube" declaraciones

    💡 Ejemplo con var:

        console.log(x); // undefined
        var x = 5;

    👉 Con let y const:

        console.log(y); // ❌ error
        let y = 5;

📘 🟤 9. REASIGNACIÓN

    🧠 Cambiar el valor de una variable

    💡 Ejemplo:

        let nombre = 'Ana';
        nombre = 'Luis'; // ✅

        const edad = 20;
        edad = 25; // ❌ error

📘 🟢 10. BUENAS PRÁCTICAS

    👉 Usar const por defecto
    👉 Usar let si necesitas cambiar el valor
    👉 Evitar var
    👉 Nombres claros (userName, totalPrice)

📘 🔵 11. DECLARACIÓN SIN VALOR

    🧠 Puedes declarar sin asignar

    💡 Ejemplo:

        let dato;

    👉 Valor inicial: undefined

📘 🟣 12. VARIABLES Y TIPOS DINÁMICOS

    🧠 JS no tiene tipos fijos

    💡 Ejemplo:

        let x = 10;
        x = 'hola';

    👉 Puede cambiar de tipo

📘 🟡 13. CONST CON ARRAYS

    🧠 No puedes reasignar, pero sí modificar

    💡 Ejemplo:

        const numeros = [1, 2, 3];
        numeros.push(4); // ✅

        numeros = []; // ❌ error

📘 🟠 14. CONST CON OBJETOS

    🧠 Igual que arrays

    💡 Ejemplo:

        const user = { nombre: 'Ana' };
        user.nombre = 'Luis'; // ✅

        user = {}; // ❌ error

⚠️ COSAS IMPORTANTES

    🧠 let y const tienen scope de bloque
    🧠 var es antiguo y problemático
    🧠 const no permite reasignación
    🧠 JS es dinámico (tipos cambian)

✨ RESUMEN

    🧠 Variables:

    👉 let → cambia valor
    👉 const → no cambia valor
    👉 var → antiguo (evitar)

    👉 Son la base para guardar datos en JS 🚀

//📘 TIPOS DE DATOS EN JAVASCRIPT

🧠 Los tipos de datos definen qué tipo de valor tiene una variable

👉 JavaScript es dinámico (el tipo puede cambiar)

📘 🟢 1. STRING (CADENA DE TEXTO)

    🧠 Representa texto

    💡 Ejemplo:

        let nombre = 'Juan';
        let saludo = "Hola";
        let mensaje = `Hola ${nombre}`;

    👉 Puede usar '', "" o `` (template strings)

📘 🔵 2. NUMBER (NÚMERO)

    🧠 Representa números (enteros y decimales)

    💡 Ejemplo:

        let edad = 25;
        let precio = 10.5;

    👉 No hay diferencia entre int y float

📘 🟣 3. BOOLEAN (BOOLEANO)

    🧠 Solo tiene dos valores

    👉 true o false

    💡 Ejemplo:

        let activo = true;
        let esMayor = false;

📘 🟡 4. NULL

    🧠 Valor intencionalmente vacío

    💡 Ejemplo:

        let usuario = null;

    👉 Significa "no hay valor"

📘 🟠 5. UNDEFINED

    🧠 Variable declarada pero sin valor

    💡 Ejemplo:

        let dato;

        console.log(dato); // undefined

    👉 JS lo asigna automáticamente

📘 🔴 6. DIFERENCIA ENTRE NULL Y UNDEFINED

    🧠 null → vacío intencional
    🧠 undefined → no asignado

📘 ⚫ 7. ARRAY

    🧠 Lista de elementos

    💡 Ejemplo:

        let numeros = [1, 2, 3];
        let nombres = ['Ana', 'Luis'];

    👉 Puede mezclar tipos:

        let mezcla = [1, 'hola', true];

📘 ⚪ 8. OBJECT (OBJETO)

    🧠 Colección de propiedades (clave: valor)

    💡 Ejemplo:

        let persona = {
          nombre: 'Ana',
          edad: 20
        };

    👉 Acceso:

        persona.nombre

📘 🟤 9. TYPEOF

    🧠 Permite saber el tipo de dato

    💡 Ejemplo:

        typeof 'hola'; // string
        typeof 10; // number
        typeof true; // boolean

    ⚠️ Detalles:

        typeof null; // object (error histórico)
        typeof []; // object

📘 🟢 10. TIPOS PRIMITIVOS

    🧠 Datos simples

    👉 string
    👉 number
    👉 boolean
    👉 null
    👉 undefined

📘 🔵 11. TIPOS COMPLEJOS

    🧠 Datos estructurados

    👉 array
    👉 object

📘 🟣 12. MUTABILIDAD

    🧠 Primitivos → inmutables
    🧠 Objetos/arrays → mutables

    💡 Ejemplo:

        let a = 10;
        a = 20; // cambia valor

        let obj = { x: 1 };
        obj.x = 2; // modifica propiedad

📘 🟡 13. ACCESO A DATOS

    🧠 Arrays por índice

        numeros[0];

    🧠 Objetos por propiedad

        persona.nombre;

📘 🟠 14. CONVERSIÓN DE TIPOS

    🧠 JS puede convertir tipos automáticamente

    💡 Ejemplo:

        '5' + 1; // '51'
        '5' - 1; // 4

⚠️ COSAS IMPORTANTES

    🧠 JS es dinámico
    🧠 null ≠ undefined
    🧠 arrays y objetos son tipo object
    🧠 typeof tiene detalles raros (null, arrays)

✨ RESUMEN

    🧠 Tipos de datos:

    👉 string → texto
    👉 number → números
    👉 boolean → true/false
    👉 null → vacío intencional
    👉 undefined → sin valor
    👉 array → listas
    👉 object → estructuras clave-valor

    👉 Base para trabajar con datos en JS 🚀

//📘 OPERADORES EN JAVASCRIPT

🧠 Los operadores permiten realizar operaciones con valores

👉 Son fundamentales para lógica y cálculos

📘 🟢 1. OPERADORES ARITMÉTICOS

    🧠 Permiten hacer operaciones matemáticas

    👉 Tipos:

        +  → suma
        -  → resta
        *  → multiplicación
        /  → división
        %  → módulo (residuo)

    💡 Ejemplo:

        let a = 10;
        let b = 3;

        console.log(a + b); // 13
        console.log(a % b); // 1

📘 🔵 2. INCREMENTO Y DECREMENTO

    🧠 Aumentan o disminuyen en 1

    💡 Ejemplo:

        let x = 5;

        x++; // 6
        x--; // 5

📘 🟣 3. OPERADORES DE COMPARACIÓN

    🧠 Comparan valores

    👉 Devuelven boolean (true/false)

    💡 Ejemplo:

        5 > 3;   // true
        5 < 3;   // false
        5 >= 5;  // true
        5 <= 4;  // false

📘 🟡 4. IGUALDAD (==)

    🧠 Compara valor (NO tipo)

    💡 Ejemplo:

        5 == '5'; // true

    👉 Hace conversión automática de tipos

📘 🟠 5. IGUALDAD ESTRICTA (===)

    🧠 Compara valor Y tipo

    💡 Ejemplo:

        5 === '5'; // false

    👉 Es más seguro y recomendado

📘 🔴 6. DIFERENCIA (!= y !==)

    🧠 Comparan desigualdad

    💡 Ejemplo:

        5 != '5';  // false
        5 !== '5'; // true

📘 ⚫ 7. OPERADORES LÓGICOS

    🧠 Permiten combinar condiciones

    👉 Tipos:

        && → AND
        || → OR
        !  → NOT

📘 ⚪ 8. AND (&&)

    🧠 Devuelve true si TODO es true

    💡 Ejemplo:

        true && true;   // true
        true && false;  // false

        5 > 3 && 10 > 5; // true

📘 🟤 9. OR (||)

    🧠 Devuelve true si AL MENOS uno es true

    💡 Ejemplo:

        true || false; // true
        false || false; // false

📘 🟢 10. NOT (!)

    🧠 Invierte el valor

    💡 Ejemplo:

        !true; // false
        !false; // true

📘 🔵 11. CORTOCIRCUITO (SHORT-CIRCUIT)

    🧠 JS puede dejar de evaluar

    💡 Ejemplo:

        false && console.log('no se ejecuta');

        true || console.log('no se ejecuta');

    👉 Optimiza ejecución

📘 🟣 12. OPERADORES CON TIPOS

    🧠 JS convierte tipos automáticamente

    💡 Ejemplo:

        '5' == 5;  // true
        '5' === 5; // false

📘 🟡 13. OR COMO VALOR POR DEFECTO

    🧠 Muy usado en JS

    💡 Ejemplo:

        let nombre = input || 'Invitado';

    👉 Si input es falso → usa 'Invitado'

📘 🟠 14. BUENAS PRÁCTICAS

    👉 Usar === en lugar de ==
    👉 Evitar conversiones implícitas
    👉 Usar operadores lógicos para condiciones claras

⚠️ COSAS IMPORTANTES

    🧠 == compara solo valor (puede confundir)
    🧠 === compara valor y tipo (recomendado)
    🧠 && y || hacen cortocircuito
    🧠 JS convierte tipos automáticamente

✨ RESUMEN

    🧠 Operadores:

    👉 Aritméticos → cálculos
    👉 Comparación → true/false
    👉 Lógicos → combinar condiciones

    👉 Base para la lógica en JavaScript 🚀


//📘 ESTRUCTURAS DE CONTROL EN JAVASCRIPT (if, switch, ternario)

🧠 Permiten tomar decisiones en el código

👉 Ejecutan diferentes bloques según condiciones

📘 🟢 1. IF

    🧠 Ejecuta código si la condición es true

    💡 Ejemplo:

        if (edad >= 18) {
          console.log('Eres mayor de edad');
        }

📘 🔵 2. ELSE

    🧠 Se ejecuta si la condición es false

    💡 Ejemplo:

        if (edad >= 18) {
          console.log('Mayor');
        } else {
          console.log('Menor');
        }

📘 🟣 3. ELSE IF

    🧠 Permite evaluar múltiples condiciones

    💡 Ejemplo:

        if (nota >= 90) {
          console.log('Excelente');
        } else if (nota >= 70) {
          console.log('Bueno');
        } else {
          console.log('Reprobado');
        }

📘 🟡 4. CONDICIONES

    🧠 Usan operadores

    👉 Comparación: >, <, ===
    👉 Lógicos: &&, ||

📘 🟠 5. SWITCH

    🧠 Evalúa múltiples casos

    💡 Ejemplo:

        let dia = 2;

        switch (dia) {
          case 1:
            console.log('Lunes');
            break;
          case 2:
            console.log('Martes');
            break;
          default:
            console.log('Otro día');
        }

    👉 break evita que siga ejecutando

📘 🔴 6. DEFAULT

    🧠 Caso por defecto

    👉 Se ejecuta si ningún case coincide

📘 ⚫ 7. COMPARACIÓN EN SWITCH

    🧠 Usa comparación estricta (===)

    💡 Ejemplo:

        '2' !== 2 → no coincide

📘 ⚪ 8. OPERADOR TERNARIO

    🧠 Forma corta de if/else

    💡 Ejemplo:

        let mensaje = edad >= 18
          ? 'Mayor'
          : 'Menor';

📘 🟤 9. SINTAXIS TERNARIO

    🧠 Estructura:

        condición ? valorSiTrue : valorSiFalse

📘 🟢 10. TERNARIOS ANIDADOS

    🧠 Se pueden encadenar

    💡 Ejemplo:

        let resultado = nota >= 90
          ? 'A'
          : nota >= 70
            ? 'B'
            : 'C';

📘 🔵 11. CUÁNDO USAR CADA UNO

    👉 if → lógica compleja
    👉 switch → múltiples casos del mismo valor
    👉 ternario → condiciones simples

📘 🟣 12. VALORES FALSY

    🧠 JS evalúa como false:

    👉 false
    👉 0
    👉 ''
    👉 null
    👉 undefined
    👉 NaN

📘 🟡 13. VALORES TRUTHY

    🧠 Todo lo demás es true

    💡 Ejemplo:

        if ('hola') {
          console.log('true');
        }

📘 🟠 14. BUENAS PRÁCTICAS

    👉 Evitar ternarios muy largos
    👉 Usar switch para muchos casos
    👉 Mantener condiciones claras
    👉 Usar === en comparaciones

⚠️ COSAS IMPORTANTES

    🧠 if evalúa condiciones
    🧠 switch usa === internamente
    🧠 ternario simplifica if/else
    🧠 entender truthy y falsy es clave

✨ RESUMEN

    🧠 Control de flujo:

    👉 if / else → decisiones
    👉 switch → múltiples casos
    👉 ternario → forma corta

    👉 Base para lógica en programas 🚀


//📘 BUCLES (LOOPS) EN JAVASCRIPT

🧠 Permiten repetir código automáticamente

👉 Evitan escribir lo mismo muchas veces

📘 🟢 1. FOR

    🧠 Bucle más usado

    💡 Estructura:

        for (inicio; condición; incremento) {
          // código
        }

    💡 Ejemplo:

        for (let i = 0; i < 5; i++) {
          console.log(i);
        }

    👉 Se usa cuando sabes cuántas veces repetir

📘 🔵 2. WHILE

    🧠 Se ejecuta mientras la condición sea true

    💡 Ejemplo:

        let i = 0;

        while (i < 5) {
          console.log(i);
          i++;
        }

    👉 Cuidado con bucles infinitos

📘 🟣 3. DO WHILE

    🧠 Se ejecuta al menos una vez

    💡 Ejemplo:

        let i = 0;

        do {
          console.log(i);
          i++;
        } while (i < 5);

    👉 Primero ejecuta, luego evalúa

📘 🟡 4. FOR...OF

    🧠 Recorre valores de un iterable

    👉 Ideal para arrays

    💡 Ejemplo:

        const numeros = [1, 2, 3];

        for (let num of numeros) {
          console.log(num);
        }

    👉 Obtienes directamente el valor

📘 🟠 5. FOR...IN

    🧠 Recorre propiedades de un objeto

    💡 Ejemplo:

        const persona = {
          nombre: 'Ana',
          edad: 20
        };

        for (let clave in persona) {
          console.log(clave);
        }

    👉 Recorre las claves (keys)

📘 🔴 6. DIFERENCIA FOR...OF vs FOR...IN

    🧠 for...of → valores
    🧠 for...in → claves

📘 ⚫ 7. BREAK

    🧠 Detiene el bucle

    💡 Ejemplo:

        for (let i = 0; i < 10; i++) {
          if (i === 5) break;
          console.log(i);
        }

📘 ⚪ 8. CONTINUE

    🧠 Salta una iteración

    💡 Ejemplo:

        for (let i = 0; i < 5; i++) {
          if (i === 2) continue;
          console.log(i);
        }

📘 🟤 9. BUCLES INFINITOS

    🧠 Ocurren cuando la condición nunca es false

    💡 Ejemplo:

        while (true) {
          console.log('infinito');
        }

    👉 ⚠️ Evitar esto

📘 🟢 10. RECORRER ARRAYS

    🧠 Varias formas:

    👉 for clásico
    👉 for...of

    💡 Ejemplo:

        const frutas = ['manzana', 'pera'];

        for (let fruta of frutas) {
          console.log(fruta);
        }

📘 🔵 11. RECORRER OBJETOS

    🧠 Con for...in

    💡 Ejemplo:

        for (let key in persona) {
          console.log(persona[key]);
        }

📘 🟣 12. USO DE ÍNDICES

    🧠 En for clásico

    💡 Ejemplo:

        const arr = [10, 20, 30];

        for (let i = 0; i < arr.length; i++) {
          console.log(arr[i]);
        }

📘 🟡 13. CUÁNDO USAR CADA UNO

    👉 for → control total
    👉 while → condición dinámica
    👉 do while → al menos una ejecución
    👉 for...of → arrays
    👉 for...in → objetos

📘 🟠 14. BUENAS PRÁCTICAS

    👉 Evitar bucles infinitos
    👉 Usar nombres claros (i, index)
    👉 Preferir for...of para arrays
    👉 No usar for...in en arrays

⚠️ COSAS IMPORTANTES

    🧠 for es el más común
    🧠 while depende de condición externa
    🧠 for...of → valores
    🧠 for...in → claves
    🧠 break y continue controlan el flujo

✨ RESUMEN

    🧠 Bucles:

    👉 Permiten repetir código
    👉 for → más usado
    👉 while → basado en condición
    👉 for...of → recorrer arrays
    👉 for...in → recorrer objetos

    👉 Clave para automatizar tareas en JS 🚀


////📘 FUNCIONES EN JAVASCRIPT (MUY IMPORTANTE 🔥)

🧠 Las funciones son bloques de código reutilizables

👉 Permiten ejecutar lógica cuando las llamas

📘 🟢 1. DECLARACIÓN DE FUNCIONES

    🧠 Forma clásica de crear funciones

    💡 Ejemplo:

        function saludar() {
          console.log('Hola');
        }

        saludar();

    👉 Se pueden llamar en cualquier momento

📘 🔵 2. PARÁMETROS

    🧠 Son valores que recibe la función

    💡 Ejemplo:

        function saludar(nombre) {
          console.log('Hola ' + nombre);
        }

        saludar('Juan');

    👉 nombre es un parámetro

📘 🟣 3. RETURN

    🧠 Devuelve un valor desde la función

    💡 Ejemplo:

        function sumar(a, b) {
          return a + b;
        }

        const resultado = sumar(2, 3);

    👉 Sin return → undefined

📘 🟡 4. FUNCIONES SIN RETURN

    🧠 Solo ejecutan código

    💡 Ejemplo:

        function mostrar() {
          console.log('Hola');
        }

    👉 No devuelven valor

📘 🟠 5. ARROW FUNCTIONS (=>)

    🧠 Forma moderna de funciones

    💡 Ejemplo:

        const sumar = (a, b) => {
          return a + b;
        };

    👉 Forma corta:

        const sumar = (a, b) => a + b;

📘 🔴 6. DIFERENCIAS FUNCTION vs ARROW

    🧠 Diferencias clave

    👉 function:
        - Tiene su propio this
        - Puede usar hoisting

    👉 arrow:
        - NO tiene this propio
        - Más corta y moderna

📘 ⚫ 7. SCOPE (ALCANCE)

    🧠 Define dónde existe una variable

    💡 Ejemplo:

        function test() {
          let x = 10;
        }

        console.log(x); // ❌ error

    👉 x solo vive dentro de la función

📘 ⚪ 8. SCOPE GLOBAL Y LOCAL

    🧠 Tipos de scope

    👉 Global:

        let a = 10;

    👉 Local:

        function test() {
          let b = 20;
        }

📘 🟤 9. PARÁMETROS POR DEFECTO

    🧠 Valores iniciales

    💡 Ejemplo:

        function saludar(nombre = 'Invitado') {
          console.log(nombre);
        }

    👉 Si no envías valor → usa el default

📘 🟢 10. FUNCIONES ANÓNIMAS

    🧠 Funciones sin nombre

    💡 Ejemplo:

        const saludo = function() {
          console.log('Hola');
        };

📘 🔵 11. FUNCIONES COMO VALORES

    🧠 Se pueden guardar o pasar

    💡 Ejemplo:

        const fn = () => console.log('Hola');

        function ejecutar(func) {
          func();
        }

        ejecutar(fn);

📘 🟣 12. HOISTING EN FUNCIONES

    🧠 Solo aplica a function

    💡 Ejemplo:

        saludar();

        function saludar() {
          console.log('Hola');
        }

    👉 Funciona aunque esté abajo

📘 🟡 13. RETURN CORTA EJECUCIÓN

    🧠 Detiene la función

    💡 Ejemplo:

        function test() {
          return 'Hola';
          console.log('Esto no se ejecuta');
        }

📘 🟠 14. BUENAS PRÁCTICAS

    👉 Funciones pequeñas
    👉 Nombres claros (getUser, calcularTotal)
    👉 Una sola responsabilidad
    👉 Evitar repetir código

📘 🔴 15. ERRORES COMUNES

    👉 Olvidar return
    👉 No pasar parámetros
    👉 Confundir this en arrow functions

⚠️ COSAS IMPORTANTES

    🧠 return devuelve valores
    🧠 arrow functions son más modernas
    🧠 scope controla el acceso a variables
    🧠 function y arrow NO son iguales

✨ RESUMEN

    🧠 Funciones:

    👉 Reutilizan código
    👉 Reciben parámetros
    👉 Devuelven valores
    👉 Controlan scope

    👉 FUNDAMENTAL en JavaScript 🚀


////📘 ARRAYS EN JAVASCRIPT (CORE 🔥)

🧠 Los arrays son listas de elementos

👉 Permiten almacenar múltiples valores en una sola variable

📘 🟢 1. ¿QUÉ ES UN ARRAY?

    🧠 Estructura de datos ordenada

    💡 Ejemplo:

        const numeros = [1, 2, 3];

    👉 Cada elemento tiene un índice (empieza en 0)

        numeros[0]; // 1

📘 🔵 2. CREAR ARRAYS

    🧠 Forma básica

    💡 Ejemplo:

        const nombres = ['Ana', 'Luis', 'Juan'];

📘 🟣 3. ACCESO Y MODIFICACIÓN

    🧠 Puedes leer y cambiar valores

    💡 Ejemplo:

        nombres[1]; // 'Luis'

        nombres[1] = 'Pedro';

📘 🟡 4. MÉTODOS BÁSICOS

    🧠 Manipulan el array

    💡 Ejemplo:

        const arr = [1, 2, 3];

        arr.push(4);    // agrega al final
        arr.pop();      // elimina último
        arr.shift();    // elimina primero
        arr.unshift(0); // agrega al inicio

📘 🟠 5. LENGTH

    🧠 Tamaño del array

    💡 Ejemplo:

        arr.length; // cantidad de elementos

📘 🔴 6. MAP

    🧠 Crea un nuevo array transformando datos

    💡 Ejemplo:

        const nums = [1, 2, 3];

        const dobles = nums.map(n => n * 2);

    👉 Resultado: [2, 4, 6]

📘 ⚫ 7. FILTER

    🧠 Filtra elementos según condición

    💡 Ejemplo:

        const nums = [1, 2, 3, 4];

        const pares = nums.filter(n => n % 2 === 0);

    👉 Resultado: [2, 4]

📘 ⚪ 8. FIND

    🧠 Devuelve el primer elemento que cumple condición

    💡 Ejemplo:

        const users = [{id:1}, {id:2}];

        const user = users.find(u => u.id === 2);

    👉 Resultado: {id: 2}

📘 🟤 9. REDUCE

    🧠 Reduce el array a un solo valor

    💡 Ejemplo:

        const nums = [1, 2, 3];

        const total = nums.reduce((acc, n) => acc + n, 0);

    👉 Resultado: 6

📘 🟢 10. FOREACH

    🧠 Recorre el array (no retorna nuevo array)

    💡 Ejemplo:

        nums.forEach(n => console.log(n));

📘 🔵 11. INCLUDES

    🧠 Verifica si un valor existe

    💡 Ejemplo:

        nums.includes(2); // true

📘 🟣 12. SOME Y EVERY

    🧠 Validaciones

    💡 Ejemplo:

        nums.some(n => n > 2);   // true
        nums.every(n => n > 0);  // true

📘 🟡 13. SLICE vs SPLICE

    🧠 Manipulación de arrays

    💡 Ejemplo:

        const arr = [1, 2, 3, 4];

        arr.slice(1, 3); // [2, 3] (no modifica)

        arr.splice(1, 2); // elimina elementos (modifica)

📘 🟠 14. SPREAD (...)

    🧠 Copiar arrays

    💡 Ejemplo:

        const copia = [...nums];

        const nuevo = [...nums, 4, 5];

📘 🔴 15. DESTRUCTURING

    🧠 Extraer valores fácilmente

    💡 Ejemplo:

        const [a, b] = nums;

📘 ⚫ 16. ARRAY DE OBJETOS

    🧠 Muy común en la vida real

    💡 Ejemplo:

        const users = [
          { id: 1, nombre: 'Ana' },
          { id: 2, nombre: 'Luis' }
        ];

📘 ⚪ 17. ENCADENAMIENTO

    🧠 Combinar métodos

    💡 Ejemplo:

        users
          .filter(u => u.id > 1)
          .map(u => u.nombre);

📘 🟤 18. INMUTABILIDAD (IMPORTANTE)

    🧠 No modificar el original

    💡 Ejemplo:

        const nuevo = nums.map(n => n * 2);

    👉 Mejor que usar push o modificar directamente

📘 🟢 19. ORDENAR ARRAYS

    🧠 Método sort

    💡 Ejemplo:

        nums.sort((a, b) => a - b);

📘 🔵 20. BUENAS PRÁCTICAS

    👉 Usar map/filter en lugar de for
    👉 No mutar arrays directamente
    👉 Usar nombres claros
    👉 Usar funciones puras

⚠️ COSAS IMPORTANTES

    🧠 map → transforma
    🧠 filter → filtra
    🧠 find → busca uno
    🧠 reduce → resume
    🧠 arrays son base del trabajo con datos

✨ RESUMEN

    🧠 Arrays:

    👉 Guardan listas de datos
    👉 Se recorren y transforman
    👉 Métodos clave:
        map
        filter
        reduce
        find

    👉 CORE del desarrollo en JS 🚀🔥


////📘 OBJETOS EN JAVASCRIPT (CORE 🔥)

🧠 Los objetos permiten almacenar datos en formato clave: valor

👉 Son fundamentales para representar entidades reales (usuarios, productos, etc.)

📘 🟢 1. ¿QUÉ ES UN OBJETO?

    🧠 Colección de propiedades

    💡 Ejemplo:

        const persona = {
          nombre: 'Ana',
          edad: 20
        };

    👉 nombre y edad son propiedades

📘 🔵 2. ACCESO A PROPIEDADES

    🧠 Puedes leer valores

    💡 Ejemplo:

        persona.nombre; // 'Ana'

        persona['edad']; // 20

📘 🟣 3. MODIFICAR PROPIEDADES

    🧠 Cambiar valores

    💡 Ejemplo:

        persona.nombre = 'Luis';

📘 🟡 4. AGREGAR PROPIEDADES

    🧠 Añadir nuevos datos

    💡 Ejemplo:

        persona.pais = 'Colombia';

📘 🟠 5. ELIMINAR PROPIEDADES

    🧠 Quitar propiedades

    💡 Ejemplo:

        delete persona.edad;

📘 🔴 6. MÉTODOS (FUNCIONES EN OBJETOS)

    🧠 Funciones dentro de objetos

    💡 Ejemplo:

        const user = {
          nombre: 'Ana',
          saludar() {
            console.log('Hola ' + this.nombre);
          }
        };

📘 ⚫ 7. THIS

    🧠 Hace referencia al objeto

    💡 Ejemplo:

        this.nombre

📘 ⚪ 8. OBJECT.KEYS / VALUES / ENTRIES

    🧠 Trabajar con propiedades

    💡 Ejemplo:

        Object.keys(persona);   // ['nombre', 'edad']
        Object.values(persona); // ['Ana', 20]
        Object.entries(persona);// [['nombre','Ana'], ['edad',20]]

📘 🟤 9. FOR...IN

    🧠 Recorrer objetos

    💡 Ejemplo:

        for (let key in persona) {
          console.log(key, persona[key]);
        }

📘 🟢 10. DESTRUCTURING

    🧠 Extraer propiedades fácilmente

    💡 Ejemplo:

        const { nombre, edad } = persona;

📘 🔵 11. SPREAD (...)

    🧠 Copiar o combinar objetos

    💡 Ejemplo:

        const nuevo = { ...persona, activo: true };

📘 🟣 12. OBJETOS ANIDADOS

    🧠 Objetos dentro de objetos

    💡 Ejemplo:

        const user = {
          nombre: 'Ana',
          direccion: {
            ciudad: 'Bogotá'
          }
        };

📘 🟡 13. OPTIONAL CHAINING (?.)

    🧠 Acceso seguro

    💡 Ejemplo:

        user.direccion?.ciudad;

    👉 Evita errores si algo no existe

📘 🟠 14. OBJECT.FREEZE / SEAL

    🧠 Controlar cambios

    💡 Ejemplo:

        Object.freeze(persona); // no se puede modificar

📘 🔴 15. COPIA vs REFERENCIA

    🧠 Los objetos se pasan por referencia

    💡 Ejemplo:

        const a = { x: 1 };
        const b = a;

        b.x = 2;

    👉 a también cambia

📘 ⚫ 16. INMUTABILIDAD (IMPORTANTE)

    🧠 Evitar modificar el original

    💡 Ejemplo:

        const nuevo = { ...persona, nombre: 'Luis' };

📘 ⚪ 17. JSON (MUY IMPORTANTE)

    🧠 Formato de datos

    💡 Ejemplo:

        JSON.stringify(persona);
        JSON.parse('{"nombre":"Ana"}');

📘 🟤 18. ARRAY DE OBJETOS

    🧠 Muy común en APIs

    💡 Ejemplo:

        const users = [
          { id: 1, nombre: 'Ana' },
          { id: 2, nombre: 'Luis' }
        ];

📘 🟢 19. COMBINAR CON MÉTODOS DE ARRAY

    🧠 Uso real

    💡 Ejemplo:

        users.map(u => u.nombre);

📘 🔵 20. BUENAS PRÁCTICAS

    👉 Usar destructuring
    👉 Evitar mutar objetos
    👉 Usar nombres claros
    👉 Mantener estructura simple

⚠️ COSAS IMPORTANTES

    🧠 Objetos = clave: valor
    🧠 this apunta al objeto
    🧠 Se pasan por referencia
    🧠 JSON es clave para APIs

✨ RESUMEN

    🧠 Objetos:

    👉 Representan datos reales
    👉 Permiten agrupar información
    👉 Se combinan con arrays

    👉 CORE del desarrollo en JS 🚀🔥


////📘 ARRAYS vs OBJETOS EN JAVASCRIPT (DIFERENCIAS Y SIMILITUDES 🔥)

🧠 Ambos son estructuras para guardar datos

👉 Son el núcleo del trabajo real en JavaScript

📘 🟢 1. SIMILITUDES

    🧠 Tienen cosas en común

    👉 Guardan múltiples valores
    👉 Son mutables (se pueden modificar)
    👉 Son tipo "object" en JS

    💡 Ejemplo:

        typeof []; // object
        typeof {}; // object

📘 🔵 2. DIFERENCIA PRINCIPAL

    🧠 Forma de organizar datos

    👉 Array → lista ordenada (índices)
    👉 Objeto → propiedades (clave: valor)

📘 🟣 3. ACCESO A DATOS

    🧠 Diferente forma de acceder

    💡 Array:

        const arr = [10, 20];
        arr[0]; // 10

    💡 Objeto:

        const obj = { x: 10 };
        obj.x; // 10

📘 🟡 4. ORDEN

    🧠 Cómo se organizan

    👉 Array → mantiene orden
    👉 Objeto → no depende del orden (aunque suele mantenerlo)

📘 🟠 5. USO PRINCIPAL

    🧠 Cuándo usar cada uno

    👉 Array:
        - Listas
        - Colecciones
        - Datos repetitivos

    👉 Objeto:
        - Entidades
        - Configuración
        - Datos estructurados

📘 🔴 6. RECORRIDO

    🧠 Cómo se recorren

    💡 Array:

        for (let item of arr) {}

    💡 Objeto:

        for (let key in obj) {}

📘 ⚫ 7. MÉTODOS

    🧠 Diferencias en funciones

    👉 Array:
        - map
        - filter
        - reduce
        - find

    👉 Objeto:
        - Object.keys()
        - Object.values()
        - Object.entries()

📘 ⚪ 8. CASO REAL (API)

    🧠 Uso combinado

    💡 Ejemplo:

        const users = [
          { id: 1, nombre: 'Ana' },
          { id: 2, nombre: 'Luis' }
        ];

    👉 Array de objetos (lo más común)

📘 🟤 9. MUTABILIDAD

    🧠 Ambos se pueden modificar

    💡 Ejemplo:

        arr.push(4);
        obj.nombre = 'Pedro';

📘 🟢 10. REFERENCIA

    🧠 Ambos se pasan por referencia

    💡 Ejemplo:

        const a = [1, 2];
        const b = a;

        b.push(3);

    👉 a también cambia

📘 🔵 11. INMUTABILIDAD (PRO)

    🧠 Evitar modificar originales

    💡 Ejemplo:

        const nuevoArr = [...arr];
        const nuevoObj = { ...obj };

📘 🟣 12. CLAVES vs ÍNDICES

    🧠 Forma de identificar datos

    👉 Array → índice (0,1,2…)
    👉 Objeto → clave (nombre, edad…)

📘 🟡 13. FLEXIBILIDAD

    🧠 Ambos pueden mezclar tipos

    💡 Ejemplo:

        const mezcla = [1, 'hola', true];

        const obj = {
          a: 1,
          b: 'hola',
          c: true
        };

📘 🟠 14. CUÁNDO USAR CADA UNO

    👉 Usa array cuando:
        - Hay lista de elementos
        - Importa el orden

    👉 Usa objeto cuando:
        - Hay propiedades con significado
        - Necesitas acceder por nombre

📘 🔴 15. ERROR COMÚN

    🧠 Confundirlos

    💡 Ejemplo:

        arr.nombre // ❌ no existe

        obj[0] // ❌ no tiene índice

⚠️ COSAS IMPORTANTES

    🧠 Arrays → listas
    🧠 Objetos → estructura clave-valor
    🧠 Ambos son tipo object
    🧠 Se usan juntos TODO el tiempo

✨ RESUMEN

    🧠 Arrays vs Objetos:

    👉 Array → colección ordenada
    👉 Objeto → datos estructurados

    👉 Similitudes:
        - Mutables
        - Tipo object
        - Se pasan por referencia

    👉 Uso real:
        Array de objetos 🔥

    👉 BASE del manejo de datos en JS 🚀

//📘 DESTRUCTURING EN JAVASCRIPT

🧠 Permite extraer valores de arrays y objetos fácilmente

👉 Hace el código más limpio y legible

📘 🟢 1. ¿QUÉ ES DESTRUCTURING?

    🧠 Forma de "desempaquetar" datos

    💡 Ejemplo:

        const persona = { nombre: 'Ana', edad: 20 };

        const { nombre, edad } = persona;

    👉 Extraes propiedades directamente

📘 🔵 2. DESTRUCTURING EN OBJETOS

    🧠 Basado en nombres de propiedades

    💡 Ejemplo:

        const user = { nombre: 'Luis', edad: 30 };

        const { nombre } = user;

📘 🟣 3. RENOMBRAR VARIABLES

    🧠 Cambiar nombre al extraer

    💡 Ejemplo:

        const { nombre: userName } = user;

📘 🟡 4. VALORES POR DEFECTO

    🧠 Si no existe la propiedad

    💡 Ejemplo:

        const { ciudad = 'Bogotá' } = user;

📘 🟠 5. DESTRUCTURING EN ARRAYS

    🧠 Basado en posición

    💡 Ejemplo:

        const numeros = [10, 20, 30];

        const [a, b] = numeros;

📘 🔴 6. SALTAR ELEMENTOS

    🧠 Ignorar posiciones

    💡 Ejemplo:

        const [ , segundo] = numeros;

📘 ⚫ 7. REST (...)

    🧠 Agrupar el resto

    💡 Ejemplo:

        const [a, ...resto] = numeros;

        const { nombre, ...otros } = user;

📘 ⚪ 8. DESTRUCTURING EN FUNCIONES

    🧠 Muy usado en parámetros

    💡 Ejemplo:

        function saludar({ nombre }) {
          console.log(nombre);
        }

📘 🟤 9. OBJETOS ANIDADOS

    🧠 Extraer propiedades profundas

    💡 Ejemplo:

        const user = {
          nombre: 'Ana',
          direccion: {
            ciudad: 'Bogotá'
          }
        };

        const { direccion: { ciudad } } = user;

📘 🟢 10. COMBINAR CON ARRAYS

    🧠 Muy común en APIs

    💡 Ejemplo:

        const users = [
          { nombre: 'Ana' },
          { nombre: 'Luis' }
        ];

        const [u1] = users;

📘 🔵 11. INTERCAMBIO DE VARIABLES

    🧠 Sin variable temporal

    💡 Ejemplo:

        let a = 1;
        let b = 2;

        [a, b] = [b, a];

📘 🟣 12. DESTRUCTURING + SPREAD

    🧠 Uso combinado

    💡 Ejemplo:

        const nuevo = { ...user, activo: true };

📘 🟡 13. ERRORES COMUNES

    👉 Nombres incorrectos en objetos
    👉 Olvidar que arrays dependen de posición
    👉 Destructuring de undefined (error)

📘 🟠 14. BUENAS PRÁCTICAS

    👉 Usar para limpiar código
    👉 Evitar destructuring muy profundo
    👉 Usar valores por defecto
    👉 Nombrar claramente

📘 🔴 15. USO REAL

    🧠 Muy común en:

    👉 React
    👉 Angular
    👉 APIs

⚠️ COSAS IMPORTANTES

    🧠 Objetos → por nombre
    🧠 Arrays → por posición
    🧠 Mejora legibilidad
    🧠 Muy usado en código moderno

✨ RESUMEN

    🧠 Destructuring:

    👉 Extrae valores fácilmente
    👉 Funciona con arrays y objetos
    👉 Permite renombrar y defaults
    👉 Hace el código más limpio

    👉 HERRAMIENTA CLAVE en JS moderno 🚀🔥


//📘 SPREAD OPERATOR (...) EN JAVASCRIPT

🧠 Permite expandir (copiar/descomponer) arrays y objetos

👉 Muy usado para copiar, combinar y manipular datos

📘 🟢 1. ¿QUÉ ES SPREAD?

    🧠 Operador ...

    👉 Expande elementos

    💡 Ejemplo:

        const nums = [1, 2, 3];

        console.log(...nums); // 1 2 3

📘 🔵 2. COPIAR ARRAYS

    🧠 Crear copia de un array

    💡 Ejemplo:

        const arr = [1, 2, 3];

        const copia = [...arr];

    👉 Evita modificar el original

📘 🟣 3. COMBINAR ARRAYS

    🧠 Unir arrays

    💡 Ejemplo:

        const a = [1, 2];
        const b = [3, 4];

        const total = [...a, ...b];

📘 🟡 4. AGREGAR ELEMENTOS

    🧠 Añadir valores fácilmente

    💡 Ejemplo:

        const nums = [1, 2];

        const nuevo = [...nums, 3, 4];

📘 🟠 5. COPIAR OBJETOS

    🧠 Clonar objetos

    💡 Ejemplo:

        const user = { nombre: 'Ana' };

        const copia = { ...user };

📘 🔴 6. COMBINAR OBJETOS

    🧠 Fusionar objetos

    💡 Ejemplo:

        const a = { x: 1 };
        const b = { y: 2 };

        const nuevo = { ...a, ...b };

📘 ⚫ 7. SOBRESCRIBIR PROPIEDADES

    🧠 Último valor gana

    💡 Ejemplo:

        const user = { nombre: 'Ana' };

        const nuevo = { ...user, nombre: 'Luis' };

📘 ⚪ 8. PASAR ARGUMENTOS

    🧠 Expandir en funciones

    💡 Ejemplo:

        const nums = [1, 2, 3];

        function sumar(a, b, c) {
          return a + b + c;
        }

        sumar(...nums);

📘 🟤 9. SPREAD vs REST

    🧠 Diferencia clave

    👉 Spread → expande
    👉 Rest → agrupa

    💡 Ejemplo:

        const [a, ...resto] = [1, 2, 3];

📘 🟢 10. INMUTABILIDAD (IMPORTANTE)

    🧠 No modificar datos originales

    💡 Ejemplo:

        const nuevo = [...nums];

        const nuevoObj = { ...user };

📘 🔵 11. COPIA SUPERFICIAL

    🧠 Spread NO copia profundamente

    💡 Ejemplo:

        const obj = { a: { x: 1 } };

        const copia = { ...obj };

        copia.a.x = 2;

    👉 obj también cambia

📘 🟣 12. USO CON ARRAYS DE OBJETOS

    🧠 Muy común

    💡 Ejemplo:

        const users = [{ id: 1 }];

        const nuevo = [...users, { id: 2 }];

📘 🟡 13. USO EN REACT / ANGULAR

    🧠 Muy utilizado

    👉 Para actualizar estados sin mutar

📘 🟠 14. BUENAS PRÁCTICAS

    👉 Usar para copiar datos
    👉 Evitar mutaciones directas
    👉 Entender que es copia superficial
    👉 Usar con destructuring

📘 🔴 15. ERRORES COMUNES

    👉 Pensar que copia todo profundamente
    👉 Sobrescribir sin querer
    👉 Confundir con rest

⚠️ COSAS IMPORTANTES

    🧠 ... expande datos
    🧠 Funciona con arrays y objetos
    🧠 No hace copia profunda
    🧠 Clave para código moderno

✨ RESUMEN

    🧠 Spread operator:

    👉 Copia arrays y objetos
    👉 Combina datos
    👉 Evita mutaciones
    👉 Expande valores

    👉 HERRAMIENTA ESENCIAL en JS 🚀🔥

////📘 PROGRAMACIÓN ORIENTADA A OBJETOS EN JAVASCRIPT (POO 🔥)

🧠 Permite organizar el código usando objetos y clases

👉 Facilita la reutilización y estructura del código

📘 🟢 1. ¿QUÉ ES POO?

    🧠 Paradigma basado en objetos

    👉 Representa entidades reales (usuario, producto, etc.)

📘 🔵 2. CLASES (CLASS)

    🧠 Plantillas para crear objetos

    💡 Ejemplo:

        class Persona {
          nombre = 'Ana';
        }

    👉 Se usan para crear instancias

📘 🟣 3. CONSTRUCTOR

    🧠 Método que se ejecuta al crear un objeto

    💡 Ejemplo:

        class Persona {
          constructor(nombre, edad) {
            this.nombre = nombre;
            this.edad = edad;
          }
        }

        const p1 = new Persona('Ana', 20);

📘 🟡 4. THIS

    🧠 Hace referencia a la instancia actual

    💡 Ejemplo:

        this.nombre

📘 🟠 5. MÉTODOS

    🧠 Funciones dentro de la clase

    💡 Ejemplo:

        class Persona {
          saludar() {
            console.log('Hola');
          }
        }

📘 🔴 6. INSTANCIAS

    🧠 Objetos creados a partir de una clase

    💡 Ejemplo:

        const p1 = new Persona('Ana', 20);

📘 ⚫ 7. HERENCIA

    🧠 Una clase hereda de otra

    💡 Ejemplo:

        class Animal {
          hablar() {
            console.log('Sonido');
          }
        }

        class Perro extends Animal {}

📘 ⚪ 8. SUPER

    🧠 Llama al constructor padre

    💡 Ejemplo:

        class Perro extends Animal {

📘 🟤 9. SOBRESCRITURA (OVERRIDE)

    🧠 Cambiar comportamiento heredado

    💡 Ejemplo:

        class Perro extends Animal {
          hablar() {
            console.log('Guau');
          }
        }

📘 🟢 10. ENCAPSULACIÓN

    🧠 Ocultar datos internos

    💡 Ejemplo:

        class Cuenta {
          #saldo = 0;

            this.#saldo += cantidad;
          }
        }

📘 🔵 11. GETTERS Y SETTERS

    🧠 Controlar acceso a propiedades

    💡 Ejemplo:

        class Persona {

    🧠 No requieren instancia

    💡 Ejemplo:

    🧠 Usar objetos dentro de otros

    💡 Ejemplo:

        class Motor {}

        }

📘 🟠 14. BUENAS PRÁCTICAS

    👉 Clases con una sola responsabilidad
    👉 Nombres claros
    👉 Usar encapsulación
    👉 Evitar clases gigantes

📘 🔴 15. ERRORES COMUNES

    👉 Olvidar usar new
    👉 Mal uso de this
    👉 No usar constructor correctamente

⚠️ COSAS IMPORTANTES

    🧠 class es una plantilla
    🧠 constructor inicializa datos
    🧠 this referencia la instancia
    🧠 extends permite herencia
    🧠 # crea propiedades privadas

✨ RESUMEN

    🧠 POO:

    👉 Clases → plantillas
    👉 Objetos → instancias
    👉 Métodos → funciones
    👉 Herencia → reutilización
    👉 Encapsulación → control

    👉 BASE para estructurar apps grandes en JS 🚀🔥



//📘 ASINCRONÍA EN JAVASCRIPT (CLAVE 🔥🔥)

🧠 Permite ejecutar tareas sin bloquear el hilo principal

👉 Fundamental para APIs, timers, eventos, etc.

📘 🟢 1. ¿QUÉ ES ASINCRONÍA?

    🧠 JS ejecuta una cosa a la vez (single thread)

    👉 Pero puede manejar tareas en segundo plano

    💡 Ejemplo:

        console.log('1');

        setTimeout(() => {
          console.log('2');
        }, 1000);

        console.log('3');

    👉 Resultado:

        1
        3
        2

📘 🔵 2. CALLBACKS

    🧠 Función que se ejecuta después

    👉 Se pasa como argumento

    💡 Ejemplo:

        function saludar(nombre, callback) {
          console.log('Hola ' + nombre);
          callback();
        }

        saludar('Ana', () => {
          console.log('Adiós');
        });

    👉 Se usa en:
        - Eventos
        - setTimeout
        - APIs antiguas

📘 🟣 3. PROBLEMA: CALLBACK HELL

    🧠 Muchas funciones anidadas

    💡 Ejemplo:

        setTimeout(() => {
          console.log('1');
          setTimeout(() => {
            console.log('2');
            setTimeout(() => {
              console.log('3');
            }, 1000);
          }, 1000);
        }, 1000);

    👉 Código difícil de leer 😵

📘 🟡 4. PROMESAS (PROMISE)

    🧠 Objeto que representa un valor futuro

    👉 Estados:
        - pending
        - fulfilled
        - rejected

📘 🟠 5. CREAR UNA PROMESA

    💡 Ejemplo:

        const promesa = new Promise((resolve, reject) => {
          const ok = true;

          if (ok) resolve('Todo bien');
          else reject('Error');
        });

📘 🔴 6. CONSUMIR PROMESAS (.then / .catch)

    🧠 Manejar resultado

    💡 Ejemplo:

        promesa
          .then(res => console.log(res))
          .catch(err => console.error(err));

📘 ⚫ 7. ENCADENAR PROMESAS

    🧠 Evita callback hell

    💡 Ejemplo:

        getData()
          .then(data => process(data))
          .then(result => console.log(result))
          .catch(err => console.error(err));

📘 ⚪ 8. ASYNC / AWAIT

    🧠 Sintaxis moderna para promesas

    👉 Hace el código más limpio

📘 🟤 9. USAR ASYNC / AWAIT

    💡 Ejemplo:

        async function obtenerDatos() {
          try {
            const res = await fetch('api');
            const data = await res.json();
            console.log(data);
          } catch (error) {
            console.error(error);
          }
        }

📘 🟢 10. TRY / CATCH

    🧠 Manejo de errores

    💡 Ejemplo:

        try {
          // código
        } catch (error) {
          console.error(error);
        }

📘 🔵 11. FETCH (APIs)

    🧠 Permite hacer peticiones HTTP

    👉 Devuelve una promesa

📘 🟣 12. EJEMPLO FETCH

    💡 Ejemplo:

        fetch('https://api.com/users')
          .then(res => res.json())
          .then(data => console.log(data));

📘 🟡 13. FETCH CON ASYNC/AWAIT

    💡 Ejemplo:

        async function getUsers() {
          const res = await fetch('https://api.com/users');
          const data = await res.json();
          console.log(data);
        }

📘 🟠 14. CUÁNDO USAR CADA UNO

    👉 Callbacks:
        - Eventos simples

    👉 Promesas:
        - Flujo async más limpio

    👉 async/await:
        - Código moderno y legible

📘 🔴 15. PARALELISMO (Promise.all)

    🧠 Ejecutar varias promesas

    💡 Ejemplo:

        Promise.all([p1, p2])
          .then(([r1, r2]) => console.log(r1, r2));

📘 ⚫ 16. EVENT LOOP (BÁSICO)

    🧠 Maneja async en JS

    👉 Call Stack + Queue

📘 ⚪ 17. MICROTASKS vs TASKS

    🧠 Orden de ejecución

    👉 Promises → microtasks
    👉 setTimeout → tasks

📘 🟤 18. ERROR COMÚN

    👉 Olvidar await
    👉 No usar try/catch
    👉 No retornar promesas

📘 🟢 19. BUENAS PRÁCTICAS

    👉 Usar async/await
    👉 Manejar errores siempre
    👉 Evitar callback hell
    👉 Usar Promise.all cuando sea necesario

📘 🔵 20. FLUJO REAL

    🧠 Usuario → petición → espera → respuesta → UI

⚠️ COSAS IMPORTANTES

    🧠 JS no es paralelo, pero maneja async
    🧠 Promesas representan valores futuros
    🧠 async/await simplifica todo
    🧠 fetch es clave para APIs

✨ RESUMEN

    🧠 Asincronía:

    👉 Callbacks → base
    👉 Promesas → mejor control
    👉 async/await → código limpio
    👉 fetch → consumo de APIs

    👉 CLAVE para aplicaciones reales 🚀🔥🔥



//📘 MANEJO AVANZADO DE JAVASCRIPT (NIVEL PRO 🔥)

🧠 Conceptos clave para entender cómo funciona JS internamente

👉 Muy importantes para entrevistas y código real

📘 🟢 1. CLOSURES

    🧠 Una función que recuerda variables de su entorno

    👉 Puede acceder a variables externas aunque ya terminó su ejecución

    💡 Ejemplo:

        function crearContador() {
          let contador = 0;

          return function() {
            contador++;
            return contador;
          };
        }

        const contar = crearContador();

        contar(); // 1
        contar(); // 2

    👉 contador sigue "vivo" gracias al closure

📘 🔵 2. ¿CUÁNDO USAR CLOSURES?

    👉 Encapsular datos
    👉 Crear funciones privadas
    👉 Mantener estado

📘 🟣 3. HOISTING

    🧠 JS "eleva" declaraciones al inicio

    💡 Ejemplo:

        console.log(x); // undefined
        var x = 5;

📘 🟡 4. HOISTING CON LET Y CONST

    🧠 No se pueden usar antes de declarar

    💡 Ejemplo:

        console.log(a); // ❌ error
        let a = 10;

📘 🟠 5. HOISTING EN FUNCIONES

    🧠 Solo function se eleva completamente

    💡 Ejemplo:

        saludar();

        function saludar() {
          console.log('Hola');
        }

    👉 Arrow functions NO

📘 🔴 6. EVENT LOOP (CONCEPTUAL)

    🧠 Sistema que maneja asincronía

    👉 Componentes:
        - Call Stack
        - Callback Queue
        - Event Loop

📘 ⚫ 7. EJEMPLO EVENT LOOP

    💡 Ejemplo:

        console.log('1');

        setTimeout(() => {
          console.log('2');
        }, 0);

        console.log('3');

    👉 Resultado:

        1
        3
        2

📘 ⚪ 8. ORDEN DE EJECUCIÓN

    🧠 Primero síncrono, luego async

📘 🟤 9. MICROTASKS vs TASKS

    🧠 Prioridad en ejecución

    👉 Promesas → microtasks (más prioridad)
    👉 setTimeout → tasks

📘 🟢 10. THIS (CLAVE 🔥)

    🧠 Depende de cómo se ejecuta la función

📘 🔵 11. THIS EN OBJETOS

    🧠 Apunta al objeto

    💡 Ejemplo:

        const user = {
          nombre: 'Ana',
          saludar() {
            console.log(this.nombre);
          }
        };

📘 🟣 12. THIS EN FUNCIONES

    🧠 Depende del contexto

    💡 Ejemplo:

        function test() {
          console.log(this);
        }

📘 🟡 13. THIS EN ARROW FUNCTIONS

    🧠 NO tiene this propio

    👉 Hereda del contexto padre

    💡 Ejemplo:

        const obj = {
          nombre: 'Ana',
          saludar: () => {
            console.log(this.nombre);
          }
        };

📘 🟠 14. THIS EN EVENTOS

    🧠 Apunta al elemento

    💡 Ejemplo:

        btn.addEventListener('click', function() {
          console.log(this); // botón
        });

📘 🔴 15. BIND, CALL, APPLY

    🧠 Controlar this

    💡 Ejemplo:

        function saludar() {
          console.log(this.nombre);
        }

        saludar.call({ nombre: 'Ana' });

📘 ⚫ 16. CLOSURE + ASYNC

    🧠 Muy común

    💡 Ejemplo:

        for (var i = 0; i < 3; i++) {
          setTimeout(() => console.log(i), 1000);
        }

    👉 Resultado: 3,3,3 (closure + var)

📘 ⚪ 17. SOLUCIÓN CON LET

    💡 Ejemplo:

        for (let i = 0; i < 3; i++) {
          setTimeout(() => console.log(i), 1000);
        }

    👉 Resultado: 0,1,2

📘 🟤 18. ERRORES COMUNES

    👉 No entender this
    👉 Confundir hoisting
    👉 Problemas con closures
    👉 Async mal entendido

📘 🟢 19. BUENAS PRÁCTICAS

    👉 Usar let/const en lugar de var
    👉 Preferir arrow functions (pero entender this)
    👉 Entender closures
    👉 Manejar async correctamente

📘 🔵 20. NIVEL PRO

    🧠 Estos temas marcan la diferencia

    👉 Entrevistas técnicas
    👉 Código complejo
    👉 Debugging avanzado

⚠️ COSAS IMPORTANTES

    🧠 Closures guardan estado
    🧠 Hoisting mueve declaraciones
    🧠 Event loop maneja async
    🧠 this depende del contexto

✨ RESUMEN

    🧠 JS avanzado:

    👉 Closures → memoria de funciones
    👉 Hoisting → elevación
    👉 Event loop → asincronía
    👉 this → contexto dinámico

    👉 NIVEL PRO en JavaScript 🚀🔥



//📘 MÓDULOS EN JAVASCRIPT (ORGANIZACIÓN DE CÓDIGO 🔥)

🧠 Permiten dividir el código en archivos reutilizables

👉 Mejoran la organización y mantenimiento

📘 🟢 1. ¿QUÉ ES UN MÓDULO?

    🧠 Un archivo JS independiente

    👉 Puede exportar e importar código

    💡 Ejemplo:

        // math.js

        export const sumar = (a, b) => a + b;

📘 🔵 2. EXPORT

    🧠 Permite compartir código

    👉 Tipos:
        - export (nombrado)
        - export default

📘 🟣 3. EXPORT NOMBRADO

    🧠 Puedes exportar varios

    💡 Ejemplo:

        export const sumar = (a, b) => a + b;
        export const restar = (a, b) => a - b;

📘 🟡 4. IMPORT NOMBRADO

    🧠 Importar funciones específicas

    💡 Ejemplo:

        import { sumar, restar } from './math.js';

📘 🟠 5. EXPORT DEFAULT

    🧠 Exporta uno principal

    💡 Ejemplo:

        export default function saludar() {
          console.log('Hola');
        }

📘 🔴 6. IMPORT DEFAULT

    🧠 Se importa sin llaves

    💡 Ejemplo:

        import saludar from './saludo.js';

📘 ⚫ 7. IMPORTAR TODO

    🧠 Importar todo como objeto

    💡 Ejemplo:

        import * as math from './math.js';

        math.sumar(2, 3);

📘 ⚪ 8. RENOMBRAR IMPORTS

    🧠 Cambiar nombres

    💡 Ejemplo:

        import { sumar as add } from './math.js';

📘 🟤 9. ORGANIZACIÓN DE ARCHIVOS

    🧠 Separar responsabilidades

    👉 Ejemplo:

        /services
        /utils
        /components

📘 🟢 10. VENTAJAS

    👉 Código limpio
    👉 Reutilizable
    👉 Fácil mantenimiento
    👉 Escalable

📘 🔵 11. IMPORTACIÓN DINÁMICA

    🧠 Cargar módulos cuando se necesiten

    💡 Ejemplo:

        const module = await import('./math.js');

📘 🟣 12. USO EN NAVEGADOR

    🧠 Necesita type="module"

    💡 Ejemplo:

        <script type="module" src="main.js"></script>

📘 🟡 13. EXTENSIONES

    🧠 Importaciones deben tener .js

    💡 Ejemplo:

        import { sumar } from './math.js';

📘 🟠 14. SCOPE DE MÓDULOS

    🧠 Cada archivo tiene su propio scope

    👉 Evita conflictos de variables

📘 🔴 15. ERRORES COMUNES

    👉 Olvidar export
    👉 Rutas incorrectas
    👉 Confundir default vs nombrado

📘 ⚫ 16. REEXPORTAR

    🧠 Exportar desde otro archivo

    💡 Ejemplo:

        export * from './math.js';

📘 ⚪ 17. BUENAS PRÁCTICAS

    👉 Un módulo = una responsabilidad
    👉 Usar nombres claros
    👉 Agrupar lógica relacionada
    👉 Evitar archivos gigantes

📘 🟤 18. ESTRUCTURA REAL

    🧠 Ejemplo:

        /api
        /helpers
        /models

📘 🟢 19. DIFERENCIA CON SCRIPT NORMAL

    🧠 Modules vs scripts

    👉 Modules:
        - Scope propio
        - Strict mode
        - Import/export

📘 🔵 20. CUÁNDO USAR

    👉 Proyectos grandes
    👉 Código organizado
    👉 Reutilización

⚠️ COSAS IMPORTANTES

    🧠 import/export conectan archivos
    🧠 default es uno, nombrados varios
    🧠 módulos tienen scope propio
    🧠 base para apps grandes

✨ RESUMEN

    🧠 Módulos:

    👉 Dividen el código
    👉 Permiten reutilizar
    👉 Organizan proyectos

    👉 CLAVE para escalar aplicaciones 🚀🔥




//📘 BUENAS PRÁCTICAS EN JAVASCRIPT (CLEAN CODE 🔥)

🧠 Son reglas para escribir código limpio, entendible y mantenible

👉 Marcan la diferencia entre código amateur y profesional

📘 🟢 1. CLEAN CODE

    🧠 Código fácil de leer y entender

    👉 Debe parecer escrito para humanos, no solo para máquinas

    💡 Ejemplo:

        // ❌ Malo
        let x = 10;

        // ✅ Bueno
        let edadUsuario = 10;

📘 🔵 2. DRY (DON'T REPEAT YOURSELF)

    🧠 No repetir código innecesariamente

    💡 Ejemplo:

        // ❌ Malo
        function saludar1() { console.log('Hola Ana'); }
        function saludar2() { console.log('Hola Luis'); }

        // ✅ Bueno
        function saludar(nombre) {
          console.log('Hola ' + nombre);
        }

📘 🟣 3. NOMBRADO DE VARIABLES

    🧠 Nombres claros y descriptivos

    👉 Evitar nombres genéricos

    💡 Ejemplo:

        // ❌ Malo
        let a = 5;

        // ✅ Bueno
        let totalProductos = 5;

📘 🟡 4. FUNCIONES PEQUEÑAS

    🧠 Una función = una responsabilidad

    💡 Ejemplo:

        // ❌ Malo
        function procesarTodo() {}

        // ✅ Bueno
        function validar() {}
        function guardar() {}

📘 🟠 5. EVITAR CÓDIGO MUERTO

    🧠 Código que no se usa

    👉 Eliminarlo

📘 🔴 6. CONSISTENCIA

    🧠 Mantener estilo uniforme

    👉 Ejemplo:
        camelCase en variables

📘 ⚫ 7. COMENTARIOS

    🧠 Solo cuando aportan valor

    👉 No explicar lo obvio

📘 ⚪ 8. ESTRUCTURA DE PROYECTO

    🧠 Organizar archivos correctamente

    💡 Ejemplo:

        /components
        /services
        /utils
        /models

📘 🟤 9. SEPARACIÓN DE RESPONSABILIDADES

    🧠 Cada archivo hace una cosa

📘 🟢 10. EVITAR FUNCIONES LARGAS

    🧠 Mejor dividir lógica

📘 🔵 11. USAR CONST Y LET

    🧠 Evitar var

📘 🟣 12. EVITAR SIDE EFFECTS

    🧠 Funciones puras

    💡 Ejemplo:

        function sumar(a, b) {
          return a + b;
        }

📘 🟡 13. VALIDACIONES

    🧠 Validar datos siempre

📘 🟠 14. MANEJO DE ERRORES

    🧠 Usar try/catch

📘 🔴 15. USO DE MÓDULOS

    🧠 Separar código en archivos

📘 ⚫ 16. REUTILIZACIÓN

    🧠 Crear funciones reutilizables

📘 ⚪ 17. LEGIBILIDAD > COMPLEJIDAD

    🧠 Código simple es mejor

📘 🟤 18. EVITAR ANIDACIONES PROFUNDAS

    🧠 Código difícil de leer

📘 🟢 19. EJEMPLO REAL

    💡 Malo:

        if (a) {
          if (b) {
            if (c) {}
          }
        }

    💡 Bueno:

        if (!a || !b || !c) return;

📘 🔵 20. MENTALIDAD PRO

    🧠 Escribir código para otros devs

⚠️ COSAS IMPORTANTES

    🧠 Código limpio = fácil de mantener
    🧠 DRY evita duplicación
    🧠 Naming es clave
    🧠 Estructura mejora escalabilidad

✨ RESUMEN

    🧠 Buenas prácticas:

    👉 Clean code → legibilidad
    👉 DRY → no repetir
    👉 Naming → claridad
    👉 Estructura → orden

    👉 NIVEL PRO en desarrollo 🚀🔥




//📘 HERRAMIENTAS MODERNAS EN JAVASCRIPT (ECOSISTEMA 🔥)

//📘 TESTING EN JAVASCRIPT (NIVEL PRO 🔥)

🧠 Permite verificar que tu código funciona correctamente

👉 Evita errores y mejora la calidad del software

📘 🟢 1. ¿QUÉ ES TESTING?

    🧠 Probar el código automáticamente

    👉 Validar que hace lo que debe

📘 🔵 2. UNIT TESTING

    🧠 Pruebas de unidades pequeñas

    👉 Se prueba una función o parte específica

    💡 Ejemplo:

        function sumar(a, b) {
          return a + b;
        }

    👉 Se prueba solo esa función

📘 🟣 3. ¿POR QUÉ USAR TESTING?

    👉 Detectar errores
    👉 Evitar bugs en producción
    👉 Facilitar cambios
    👉 Código más confiable

📘 🟡 4. TIPOS DE TEST

    🧠 Principales:

    👉 Unit → funciones pequeñas
    👉 Integration → varias partes
    👉 E2E → flujo completo

📘 🟠 5. JEST (¿QUÉ ES?)

    🧠 Framework de testing para JS

    👉 Muy usado (React, Node, etc.)

📘 🔴 6. INSTALAR JEST

    💡 Ejemplo:

        npm install jest --save-dev

📘 ⚫ 7. PRIMER TEST

    🧠 Estructura básica

    💡 Ejemplo:

        test('suma correctamente', () => {
          expect(1 + 2).toBe(3);
        });

📘 ⚪ 8. EXPECT

    🧠 Validación

    👉 Compara resultado esperado

📘 🟤 9. MATCHERS

    🧠 Métodos de comparación

    💡 Ejemplo:

        expect(2 + 2).toBe(4);
        expect(true).toBeTruthy();
        expect(arr).toContain(3);

📘 🟢 10. TESTEAR FUNCIONES

    💡 Ejemplo:

        function sumar(a, b) {
          return a + b;
        }

        test('suma 2 + 3', () => {
          expect(sumar(2, 3)).toBe(5);
        });

📘 🔵 11. BEFORE / AFTER

    🧠 Preparar entorno

    💡 Ejemplo:

        beforeEach(() => {
          // setup
        });

📘 🟣 12. TEST ASÍNCRONOS

    🧠 Probar async

    💡 Ejemplo:

        test('fetch data', async () => {
          const data = await getData();
          expect(data).toBeDefined();
        });

📘 🟡 13. MOCKS

    🧠 Simular funciones o APIs

    💡 Ejemplo:

        jest.fn();

📘 🟠 14. SNAPSHOTS

    🧠 Guardar estado de UI

📘 🔴 15. COVERAGE

    🧠 Qué tanto código está testeado

    💡 Ejemplo:

        npm run test -- --coverage

📘 ⚫ 16. ESTRUCTURA

    🧠 Archivos de test

    👉 nombre.test.js
    👉 __tests__/

📘 ⚪ 17. BUENAS PRÁCTICAS

    👉 Tests simples
    👉 Un test = una cosa
    👉 Nombres claros
    👉 No depender de datos externos

📘 🟤 18. ERRORES COMUNES

    👉 Tests muy complejos
    👉 No testear errores
    👉 No testear async

📘 🟢 19. CUÁNDO TESTEAR

    👉 Lógica importante
    👉 Funciones críticas
    👉 APIs

📘 🔵 20. NIVEL PRO

    🧠 Testing es obligatorio en empresas

⚠️ COSAS IMPORTANTES

    🧠 Testing valida tu código
    🧠 Unit testing prueba funciones
    🧠 Jest es el más usado
    🧠 expect compara resultados

✨ RESUMEN

    🧠 Testing:

    👉 Unit testing → funciones
    👉 Jest → framework
    👉 expect → validaciones
